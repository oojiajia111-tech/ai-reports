一句话 可复用的不是轨迹，是「怎么抓」——路线每任务给一次，抓法从模板库拿
方向 训练数据
💡 第一性原理核心立论

灵巧手的数据瓶颈不是没有演示，是每换一个物体就得重新演示一遍。DexLink 把一段演示拆成两半：物体该走的路，和手该怎么抓住它。路用几个路点描述，抓法用交互模板描述，模板可以换物体复用；中间缺的轨迹直接插值，反正后面的强化学习会把它修成动力学可行的。它真正的主张是——可复用的从来不是轨迹，而是「抓法」这件事本身。

What是什么：把「一段演示」拆成「路点 + 模板」

先看它换掉了什么。传统做法是「一段完整演示喂给策略」，它换成了两样更小的东西：

拆出来的部分怎么表示复用性谁提供
物体该走的路物体位姿路点序列（s0 到 sK），每点带时间戳（含关节值时也带）与物体、任务强绑定，每任务写一次人手写 / 智能体辅助
手该怎么抓交互模板：源物体网格 + 源物体坐标系下的人手关键点 + 源→目标旋转与物体弱绑定——可以跨尺度、跨实例、跨类别搬OakInk（287 个交互 / 33 类）、ARCTIC
中间那段轨迹不在物体坐标系里插值（腕变换在物体系内插值、旋转用球面插值）—算法生成，不要求动力学可行
动力学可行性残差 PPO：在参考轨迹上叠一个小的修正量—仿真里自己学

这个拆法的锋利之处在于：它把「采集成本」从「任务 × 物体」降到了「任务 + 物体类别」。加一个新物体，不用重新演示，从模板库里挑一个抓法、重定向到新几何上就行。

Why为什么：两条合成数据的路，卡在同一件事上

第 1 步：仿真合成数据的两条老路，各有各的瓶颈
一条靠人类演示（遥操作、动捕、视频标注）：采集贵、难规模化，且演示绑定在特定的「任务-物体」对上。另一条靠通用奖励函数 / 手部先验：便宜，但对「手指-物体到底怎么接触」控制力很弱，容易生成物理上成立、但人类看着别扭的动作。
第 2 步：「演示」这个单位太粗了
一段演示里混着两件性质完全不同的事：物体要去哪（任务语义，随物体变），和手要怎么抓（接触模式，跨物体很稳）。把它们捆在一起，就只能在「重新演示一遍」和「用通用奖励瞎试」之间二选一。
第 3 步：这两件事的可复用性差一个量级
「把杯子抬到 15 厘米」换一个杯子就完全不同；但「从侧面握住圆柱体、拇指对掌」换个杯子照样成立。既然复用性不同，就该拆开、按各自的粒度复用。这就是模板化的全部动机。
第 4 步：拆开之后，中间那段轨迹就不必是「真轨迹」了
这是最聪明的一步取舍：既然末端有 RL 精修，参考轨迹就不需要动力学可行，只需要「把探索的偏见往正确方向拉」。于是不必解轨迹优化、不必保证可执行，直接插值就行。原文写得很明确：参考只要求「把 RL 的探索偏见往意图行为上拉」。
第 5 步：但插值会带来「跟着参考走」的系统偏差
如果策略直接输出绝对动作，参考一旦不完美，误差会累积、且无法修正。所以用残差形式：输出对参考的有界修正量。消融印证了这一点——Delta 动作在长程任务（叠三个方块）上完全失败（0.0），残差形式 100%。

How怎么做：重定向 → 链接 → 残差 RL

一、物体感知重定向：不匹配手指位置，匹配「手与物体的关系」

最朴素的重定向是「让机器人指尖去够人类指尖的位置」（fingertip IK）。问题很明显：人手和机械手的连杆长度不同，指尖对上不等于抓法对上。所以 DexLink 同时保两件事：

  • 手内构型：腕→指尖、指根→指尖、拇指对掌、手掌朝向三重点——这几组相对关系要对上，而不是绝对坐标对上；
  • 手物关系：用 BPS（Basis Point Set）描述子比较「每个手部关键点到物体表面的距离、方向、法向、局部特征」。这是在比「手贴着物体的哪个部位、贴成什么样」，而不是比坐标。

实现细节：SNOPT 求解、容差 1e-4、物体表面采 512 点、BPS 用 39 个手部关键点 × 9 通道 = 351 维；关系项权重 λ = 1e-3。最后做穿透处理：对手指关节组做顺序线搜索消除机器人与物体的穿插，并把「源模板里标记为接触」的关键点压向物体表面。

二、参考轨迹链接：在物体坐标系里插值

相邻两个带模板的路点之间，用归一化时间 alpha 插值（alpha 从 0 走到 1）。关键设计：腕部变换在物体坐标系内插值，然后乘上当前物体位姿。这样物体在动的时候，手与物体的相对关系近似保持不变——如果直接在世界上插值，物体一转，手就「脱手」了。

三、残差 RL：参考给方向，策略修细节

观测 116 维（本体感知 + 接触信号 + 腕相对物体状态 + 参考状态 + 归一化任务进度），动作 18 维（腕平移 3 + 腕旋转 3 + 12 个手关节）。奖励五项加权：物体跟踪 0.625 / 手构型相似 0.083 / 手物关系相似 0.083 / 重定向关节接近 0.167 / 关节平滑 0.042，完成再给 +10。

还有一个不显眼但很关键的技巧：reset 时沿参考轨迹按访问密度取初始时间步（负指数相关）。这样长程任务的每个阶段都能被并行学到，而不是每次从第一步重来。消融显示：只从初始状态 reset，香蕉交接任务从 86.7% 掉到 30.0%。

Formula核心公式：一个重定向、一个链接、一个奖励

式 1　物体感知重定向：构型 + 关系，两项一起压（原文核心式）
\[ (\mathbf{w}_k^{\star},q_k^{\star})=\arg\min_{\mathbf{w}_k\in SE(3),\,q_k}\Big[\mathcal{L}_{\mathrm{cfg}}\big(\mathbf{w}_k\!\cdot\!\mathrm{FK}(q_k),\bar{P}^{h}_k\big)+\lambda\,\mathcal{L}_{\mathrm{rel}}\big(\mathbf{w}_k\!\cdot\!\mathrm{FK}(q_k),\mathcal{M}^{\mathrm{tgt}}_k;\bar{P}^{h}_k,\bar{\mathcal{M}}^{\mathrm{src}}_k\big)\Big] \]
\(\mathbf{w}_k\) 是腕部位姿，\(q_k\) 是手部关节，\(\mathrm{FK}\) 是正运动学，\(\bar{P}^h_k\) 是旋转对齐后的人手关键点，\(\mathcal{M}^{\mathrm{tgt}}_k\) 是目标物体网格，\(\bar{\mathcal{M}}^{\mathrm{src}}_k\) 是源物体网格，\(\lambda=10^{-3}\)。
说人话：调两个东西——手整体摆在哪、手指怎么弯——让两件事同时成立：手的姿态像人手的姿态，手和物体的贴合关系也像人手与源物体的关系。
第一项 \(\mathcal{L}_{\mathrm{cfg}}\) 只在相对量上比（方向用余弦距离、未归一化向量用平方 L2），这样手大手小不影响；第二项 \(\mathcal{L}_{\mathrm{rel}}\) 才是关键，它用 BPS 描述子把「手贴着物体表面哪个点、贴着时法向朝哪」编码成 351 维去比。没有第二项，重定向出来的手会「姿势像人、但离物体半厘米」——抓不住。
式 2　参考轨迹链接：在物体坐标系里插值，物件转了手才不脱
\[ \mathbf{w}^{\mathrm{ref}}_t=T^{\mathrm{obj}}_t\cdot\mathrm{Interp}_{SE(3)}\big(\mathbf{w}^{\star}_k,\mathbf{w}^{\star}_\ell;\alpha_t\big),\qquad q^{\mathrm{ref}}_t=\mathrm{Interp}\big(q^{\star}_k,q^{\star}_\ell;\alpha_t\big),\qquad \alpha_t=\frac{t-t_k}{t_\ell-t_k} \]
\(T^{\mathrm{obj}}_t\) 是 \(t\) 时刻物体（或其关节部件）的位姿，\(\alpha_t\) 是归一化时间，旋转用球面插值、平移与关节值线性插值。
说人话：别问「手在世界里的哪儿」，先问「手相对物体在哪儿」，插完再跟着物体一起走。这样物体一边转一边被搬，手始终贴着它。
这个式子还藏着一个前提：参考轨迹不要求动力学可行。原文写得很直白——它只需要把 RL 的探索往意图方向拉。所以这里可以放心用插值，不必解一个带约束的轨迹优化。「不追求正确，只追求方向对」是整篇最省的取舍。
式 3　残差动作与奖励：参考给底，策略加修正
\[ \mathbf{w}^{\mathrm{cmd}}_t=\mathbf{w}^{\mathrm{ref}}_t\oplus\Delta\mathbf{w}_t,\quad q^{\mathrm{cmd}}_t=q^{\mathrm{ref}}_t+\Delta q_t,\quad R_t=\sum_{k\in\mathcal{K}}\bar{w}_k\,r_k(t)+w_{\mathrm{succ}}\mathbf{1}_{\mathrm{succ}}(t) \]
\((\Delta\mathbf{w}_t,\Delta q_t)\sim\pi_\theta(x_t)\) 是策略输出的有界修正，\(\oplus\) 是 \(SE(3)\) 上的加法，\(\mathcal{K}=\{\mathrm{obj},\mathrm{int},\mathrm{ref},\mathrm{smooth}\}\) 分别是物体跟踪、手物交互相似、参考跟随、关节平滑四项，\(w_{\mathrm{succ}}=10\) 是完成奖励。
说人话：参考轨迹先说「大概这么走」，策略只负责说「偏左两厘米、手指再合一点」。因为只学修正量，探索空间小了一个量级，样本效率才上得去。
五项权重的排序也值得看：物体跟踪 0.625 占了六成，手物关系只有 0.083。这说明它把「东西有没有到位」当主目标，把「抓得像不像人」当正则——不是让人手当标准答案，而是让它当「不走歪」的约束。

Worth价值与局限：把数据成本的量纲从「任务×物体」降到「任务」

值得拿走的四条

1. 「模板可复用、轨迹不必可行」是一组很省的组合。因为不要求参考物理上能跑通，就不必解轨迹优化；因为末端有残差 RL，偏差能被修。这两条合起来，把「造数据」从「录演示」变成了「选模板 + 写路点」——原文估的任务制作成本是 <1 分钟/任务（含人工核验）。
2. 重定向质量有两级指标，比只报成功率诚实。1 cm 阈值 60%、2 cm 阈值 80%，等于自己说出了「四成模板在严格条件下抓不住」。这种自曝短板的写法，比一个漂亮的 95% 更可信。
3. 跨类迁移不输专属模板，是最有工程价值的一条。苹果→鼠标、锤子→酒杯都是 1.0，而给酒杯专门生成的模板反而只有 0.67。说明「人手抓法的先验」比「为该物体定制的解」更强——这直接推翻了「必须为每个物体单独造数据」的默认假设。
4. 消融的失败模式各不相同，信息量很大。去参考 = 学不出来；去残差 = 长程崩；只从初始 reset = 后半段崩；去交互奖励 = 抓法崩。四个部件各自对应一种失败模式，这让人能判断自己该补哪一块。

必须打的五个问号

  • 它需要一个显式的任务规格，而这个东西不好搞。路点序列 + 每个路点挂哪个模板 + 源→目标旋转——这比「给一段视频」难得多。原文把这件事推给了「agentic 系统」，但那是展望，不是已实现的结果。换句话说：它省掉了演示，但把成本转移到了「写规格」上。
  • 真机只做了抓取-抬升。4 个物体、每个 10 次试验、成功判据是「举在空中约 1 分钟」。推、拧、插、双手交接这些真正难的动作，一个都没上真机。所以「零样本 sim-to-real」这个结论的适用范围很窄。
  • 20 个尺度条件里 7 个不是 100%，且 1.25× 那一档直接归零。原文自己说「极端尺度不稳定且跨种子波动」。这意味着它离「换个杯子就能用」还有距离——名义尺度附近好用，尺度一变就得重新挑模板。
  • 「1.0 成功率」要看条件数。跨类迁移表里每行是一个条件、可能只有一个种子。而部分任务变体明确写了「2/3 个种子成功、1 个完全失败」。所以那些 1.0 应当读作「在这个条件下成功过」，不是「稳定成功」。
  • 只在刚体上验证，且模板来源有限。OakInk 是静态/功能性交互、ARCTIC 是双手时序交互，可形变物体（布、绳、袋子）完全没有覆盖。而这类物体恰恰是「模板复用」最难的地方——它们的接触状态随形变而变，无法用一个静态关键点集描述。
一句话结论：如果只拿一条，就拿「把演示拆成『路线 + 抓法』，按各自的复用粒度分别复用」——这一拆，数据成本从「任务 × 物体」降到「任务 + 物体类别」；如果拿两条，第二条是「参考轨迹不要求可行」——既然末端有残差 RL，中间那段插值就够，不必解轨迹优化。但要清楚：它用「写规格」换掉了「录演示」，而那件事目前还得靠人。
