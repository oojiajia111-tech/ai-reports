Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs「把动作专家的梯度挡住、保护 VLM 别被污染」是当下 VLA 的主流配方。这篇把配方拆成两个独立开关做 2×2，发现：挡住梯度和用动作 token 监督，本质是同一条信号的两条投递路径 · 闭环路测里两条单开几乎一模一样（0.600 vs 0.601，差 0.001），两条都开才到 0.703 —— 第二条通道的边际收益只有第一条的 58% · 于是"绝缘"不是保护，是把一条宽管子换成了窄管子，而它收的保费是闭环性能的 17%

来源 arXiv 2611.05249
论文发布 2026-11-03 · arXiv 2611.05249
机构 NVIDIA · Princeton · Stanford（Marco Pavone 组）
实验 驾驶 1,434+273 场景 · 闭环 827 场景 × 5 rollout · 操作 3 任务 × 50 rollout × 2 模型族
第一性原理核心立论

现在主流的 VLA 训练配方（Knowledge Insulation / π0.5 / MolmoAct2 / Alpamayo-R1 都用它）同时做三件事：屏蔽动作专家回传给 VLM 的梯度、让 VLM 额外预测离散动作 token、用视觉语言数据共训。过去大家把这三件事当成一个整体，于是"屏蔽有效"从来没有被单独检验过。

这篇论文把它拆成两个独立开关，测出来的四格是全文最锋利的一张表：什么都不给 0.425，只给动作 token 0.600，只给梯度 0.601，两个都给 0.703（闭环路测通过率）。两条通道单独开，效果几乎一模一样；两条都开，比单开只多 0.102——第二条通道的边际收益只有第一条的 58%。

所以真正的结论不是"该不该绝缘"，而是：一个参数要获得"对控制有用"的信息，只需要存在一条从控制损失到它的梯度通路；信号本身只有一份，你把它走哪条路送进去，比走不走得进去，次要得多。「屏蔽梯度」不是保护，是降码率——你并没有阻止信息进入 VLM，只是换了一条更窄的管子。窄管子够不够用，取决于任务的带宽：开车只需要横向纵向两个平滑标量，token 够用；接触丰富的操作不够，所以那里耦合的收益反而更大（π0.5 从 10.3% 涨到 32.9%）。

问题为什么一直没被拆开 公理链：信号只有一份 2×2 设计与四格结果 值不值：保费与理赔

是什么一个被"打包出售"的设计决定

先看架构。这类 VLA 用的是 Mixture-of-Transformers（MoT）结构：一个自回归的 VLM 负责看图和读指令，一个更小的 flow-matching 动作专家逐层读取 VLM 的 K/V 表示，据此生成连续动作块。VLM 不读专家的动作输入——信息是单向的：VLM 往专家送，专家不往 VLM 送。

于是训练时出现一个岔路口：动作损失要不要回传梯度，去更新那个产生 K/V 的 VLM？

选择做法动机谁在用
耦合（coupling）让 flow loss 的梯度穿过 K/V 接口，同时更新专家和 VLM让 VLM 学到"哪些特征对精确控制有用"，两边协同适应Wall-OSS-0.5
绝缘（insulation）在 K/V 接口处 stop-gradient（或直接冻结骨干）保护预训练的视觉语言能力，别被一个随机初始化的新专家污染π0.5 · MolmoAct2 · Alpamayo-R1

问题在于：这两派从来不可比。作者的诊断很准——绝缘派的系统里几乎都还开着"离散动作 token 监督"（FAST token），而 Wall-OSS-0.5 虽然耦合，但也保留着离散动作目标和多模态目标。所以两边的差异同时混了配方、初始化、数据、优化。你没法判断"绝缘"这一项本身值多少。

这就是那类最容易被忽略的论文：它不提新模型，只是把两个一直被绑在一起卖的东西拆开，分别标价。而这类论文往往比新模型更有用，因为它的结论可以直接改你下一版的训练脚本。
作者的原话：Knowledge Insulation 报告了绝缘的好处，但没有测过"没有 FAST 监督时绝缘还成不成立"；Wall-OSS-0.5 则报告耦合更好。两个相反的结果，却都因为配方不同而无法归因。

还有一层更微妙的东西：绝缘派手里其实握着两条信号。动作 token 的交叉熵，是把同一条未来轨迹量化成离散符号再监督 VLM；专家梯度，是把同一条未来轨迹原样连续地回传给 VLM。同一个目标，两种编码。如果两种编码能互相替代，那"屏蔽梯度"这件事的价值就被高估了——这正是本文要验证的。

为什么公理链：梯度是唯一的信息通道，而信号只有一份

公理 1　没有梯度通路，参数对该损失就是常数
数学上，绝缘就是令 \(\partial\mathcal{L}_{\text{flow}}/\partial\theta=0\)（\(\theta\) 是 VLM 参数）。这不是"削弱"，是"切断"。所以如果 VLM 还是学到了对控制有用的东西，那必然来自另一条路。
式 1　两个开关写在一个式子里：绝缘就是一次 stop-gradient
\[ \mathcal{L}=\mathcal{L}_{\text{CE}}+\mathcal{L}_{\text{flow}}, \qquad \widetilde{H}_\theta= \begin{cases} H_\theta & \text{耦合（coupling）}\\[2pt] \operatorname{sg}\!\left(H_\theta\right) & \text{绝缘（insulation）} \end{cases} \] \[ \mathcal{L}_{\text{CE}}=-\mathbb{E}_{(x,y)\sim\mathcal{D}}\!\left[\frac{1}{N}\!\left(\sum_{i\in\mathcal{I}_{\text{base}}}\log p_\theta(y_i\mid x,y_{ \(H_\theta\) 是 VLM 各层产出的 K/V 表示，\(\operatorname{sg}(\cdot)\) 是 stop-gradient（前向不变、反向断开）。
关键：这两个开关是正交的。\(\mathbf{1}_{\text{action}}\) 控制"要不要用离散 token 监督动作"，\(\operatorname{sg}\) 控制"要不要用连续梯度监督动作"。以前它们被绑在一起，现在被拆成 2×2。
说人话：同一个未来轨迹，一份被翻译成离散符号喂给 VLM（CE），一份被原样连续回传（flow 梯度）。绝缘派关掉了第二条、留着第一条。那第一条够不够用？这就是全部问题。
公理 2　两条通路送的是同一个随机变量，只是码率不同
离散 token 是量化版本，损失了亚 token 精度的信息；连续梯度是无损版本，但把 VLM 直接暴露在一个随机初始化专家的梯度下。

这条公理是全文的解释框架，也是我认为它最值钱的地方：它把"保护 vs 协同"这个价值判断，翻译成了"码率 vs 风险"这个工程选择。

式 2　flow matching 目标 + 时间采样（决定梯度携带什么信息）
\[ \mathcal{L}_{\text{flow}}=\mathbb{E}_{(x,a)\sim\mathcal{D}_{\text{action}},\,t,\,\epsilon}\left[\left\|v_\phi\!\left(a_t,t;\widetilde{H}_\theta\right)-(a-\epsilon)\right\|_2^2\right], \qquad a_t=ta+(1-t)\epsilon \]
\[ b\sim\operatorname{Beta}(1.5,\,1.0),\qquad t=0.999\,(1-b),\qquad \epsilon\sim\mathcal{N}(0,I) \] \(a\) 是真实连续轨迹，\(a_t\) 是加噪后的插值点，\(v_\phi\) 是专家的速度场，\(\phi\) 是专家参数。
时间采样这个细节值得单独看：\(b\sim\text{Beta}(1.5,1)\) 且 \(t=0.999(1-b)\)，意味着训练偏向高噪声端（\(t\) 接近 1）。
说人话：\(t\) 大 = 噪声多 = "大概往哪走"；\(t\) 小 = 噪声少 = "最后几厘米怎么微调"。偏采样高噪声端，等于把训练重点放在"大方向"上，而"精细动作"那一段的梯度比较稀。
这带来一个张力：如果精调区的梯度本来就稀，那"用梯度教 VLM 精细控制"这件事的证据基础就比看起来弱——这也是后面批判里要拿回来的点。
公理 3　同一信号的第二条通道，边际收益必然递减
因为两条通道更新的是同一批参数、指向同一个目标。第一条通道把"容易拿到的信息"拿完了，第二条只剩下"第一条传不过去的那部分"——如果第一条是窄管子，这部分可能不小；如果第一条已经够宽，这部分就很小。

这条是可以用实测数字直接检验的，而且检验结果干净得不像实验数据：

式 3　通道冗余度 ρ：第二条通道值第一条的几成（本文自建诊断量，原文未定义）
\[ \rho=\frac{P(\text{双通道})-P(\text{单通道})}{P(\text{单通道})-P(\text{无通道})} =\frac{0.703-0.601}{0.601-0.425} =\frac{0.102}{0.176}\approx 0.58 \]
\(P\) 是闭环路测通过率（AlpaSim，827 场景 × 5 rollout，concurrent 训练）。单通道取"只开梯度"那一格（0.601），因为它是两条里更强的。
说人话：第一条通道值 0.176，第二条只值 0.102，打了 58 折。
换个读法更狠：0.601 vs 0.600 —— 两条通道单独使用时几乎完全等价（差 0.001，在评测噪声里）。也就是说，你随便留哪一条都行，但留哪一条都只拿到 41% 的增益；只有两条都留才能到 65%。
注意：ρ 是我为了量化"可替代性"自己构造的，论文没有这个数。它的分子分母都直接来自论文表 3，但把它叫"冗余度"是我的解读，不是作者的断言。
公理 4　窄管子够不够用，取决于任务的带宽
驾驶的动作是"加速度 + 曲率"两个平滑标量，量化损失小；操作的接触、力、瞬时贴合，量化损失大。所以同一个"绝缘"，在驾驶上几乎免费，在操作上很贵。

这条公理把论文的结论从"绝缘不该做默认"升级成一句更可操作的话："绝缘的代价，等于你的任务在 token 量化下损失掉的那部分信息。"这也是为什么论文在操作上的两个模型族里，耦合的收益都比驾驶更大——不是因为操作"更需要耦合"，而是因为操作的 token 码率更不够用。

怎么做2×2 × 3 种训练顺序，把混淆变量按死

实验骨架

  • 驾驶基座：Qwen3-VL-2B-Instruct + 同宽度的非因果 flow-matching 专家（专家逐层读 VLM 的 K/V，VLM 不读专家的动作）。专家输出 K 组未来控制量（加速度 + 曲率），再用离散化独轮车模型积出位置和朝向。
  • 四个条件：动作 token 监督 开/关 × 梯度 耦合/绝缘。
  • 三种训练顺序：并发（一起训 300k 步）、VLM 先（先单独训 VLM 100k，再引入新初始化的专家 200k）、专家先（先对冻结 VLM 训专家 100k，再联合 200k）。

最值得学的一处：掩码怎么关，才不引入新变量

关掉动作 token 监督这件事，很容易悄悄改掉别的东西。作者处理得很干净，我认为这一段该被当成"控制变量"的范本：

式 4　固定 N 的掩码不变式：关掉监督，但不许改权重
\[ N\equiv\left|\mathcal{I}_{\text{base}}\right|+\left|\mathcal{I}_{\text{action}}\right|\quad(\text{掩码前的监督位置数，两种条件下都取这个}) \]
三条配套措施：① 动作值 token 仍然 teacher-forcing 输入（只是不算 CE），所以输入分布不变；② 轨迹分隔符仍然被监督，历史轨迹 token 仍在输入上下文里；③ 把动作 token 的状态从专家的 K/V 上下文里排除，否则专家会"偷看"答案。
为什么必须固定 N：CE 是按监督位置数取平均的。如果关掉动作监督就让 N 变小，那其他项（VQA、推理、结构 token）的相对权重会自动上升——你就分不清"效果来自少了动作监督"还是"来自 VQA 权重变大"。
说人话：关一个开关的时候，要保证其他开关的刻度没被顺手拧动。这一步做不做，决定了整篇论文是"消融"还是"讲故事"。

结果一：开环，绝缘只有在"没有 token"时才吃亏

开环用 Physical AI Autonomous Vehicles 数据集：Public Golden 1,434 场景、OOD 273 场景。指标是第一个采样轨迹的 ADE，外加 6 个候选里的 minADE 作为 oracle 参考。

  • 有动作 token 监督时：绝缘和耦合差别很小（Public Golden 上绝缘甚至略好）。
  • 没有动作 token 监督时：耦合把 ADE 降了约 26%（Public Golden）和 24%（OOD）。

换句话说：绝缘是否吃亏，取决于 VLM 手里还有没有别的动作信号。这正是"可替代"的直接证据。

怎么读这张表，我给三个层次：

  1. 横向看（同一行）：并发那行是教科书级的 2×2。0.425 → 0.600/0.601 → 0.703：任一条通道单独开，都是 +41% 左右；两条都开 +65%；两条都关就是 0.425。而 0.600 和 0.601 的差只有 0.001——在 827 个场景的评测噪声里，这两格是同一个数。
  2. 纵向看（同一列）："并发"在三个训练顺序里给出最高绝对值（0.703）。这和 π0.5 / MolmoAct2 采用的"VLM 先"配方正好相反——那些配方是先训离散动作预测、再引入连续专家。作者的结论是：一开始就一起训，是个很强的简单起点。
  3. 看缺口：并发 + token 关的耦合（0.601）几乎等于并发 + token 开的绝缘（0.600）。两种完全不同的机制，给出同一个分数——这是"可替代"最直观的样子。

这组数里有两个必须注意的事：

  • 耦合的增益在"关掉 FAST"时更大：π0.5 是 10.3 → 32.9，MolmoAct2 是 14.5 → 36.5。耦合 + 无 token（32.9）比绝缘 + 有 token（19.5）高 1.7 倍。在操作上，"两条通道等价"这个结论不成立——梯度那条明显更值钱。
  • 但绝对水平很低：最好的一格 36.5%，而论文自己引用的已发布 π0.5 是 40.0%。作者解释了差距（他们的机器人数据主要来自 DROID，350 小时；已发布版本用了超过 10,000 小时），这是诚实的，但也意味着四格之间的差距是在一个整体偏低的区间里比较出来的。

结果四：理由质量——"保护语言能力"这件事，没有出现

用一个冻结的 Lingo-Judge 给生成的驾驶理由打分（与参考理由比对，分数 > 0.5 算通过）：

  • 并发 + token 开：绝缘 64.7% vs 耦合 64.9% —— 几乎完全相同。这是最直接的反证：绝缘并没有"保住"理由质量，因为耦合也没破坏它。
  • 并发 + token 关：绝缘 56.6% vs 耦合 63.5% —— 耦合反而高 6.9 个点。
  • 但 OOD 上反过来：绝缘 36.3% vs 耦合 34.8%。而在两种分段训练里，token 关时绝缘的理由质量更高（VLM 先 63.0 vs 61.3；专家先 62.0 vs 61.2），尽管它的 ADE 更差。
这组数字其实比作者说的更值得强调。它证明了两件事：① "绝缘保护 VLM 能力"这个动机，在理由质量这个最贴近的指标上，没有可复现的优势；② ADE（动作精度）和理由质量（语言质量）会朝相反方向走 —— 分段训练里绝缘 ADE 更差、理由却更好。
后者是个更麻烦的信号：说明这两个指标测的不是同一个东西，而论文拿 ADE 当主要证据去支撑闭环结论。

值不值保费收了，理赔记录是空的——但也可能是没测到理赔场景

先给价值：三条能直接改训练脚本

  1. 别再默认开绝缘。如果你的配方里已经有动作 token 监督 + 视觉语言共训，那额外屏蔽专家梯度几乎不带来任何保护（64.7 vs 64.9），而在并发训练下要付 17% 的闭环代价（0.600 → 0.703）。这一条可以直接省掉一个超参。
  2. 并发训练 > VLM 先。三个训练顺序里，并发的绝对值最高（0.703），而 π0.5 / MolmoAct2 的"VLM 先"配方在同样的场景下只有 0.646~0.648。"先教它说，再教它动"这个顺序，可能一直是个次优的工程习惯。
  3. 做消融时，关开关别顺手改刻度。固定 N、teacher-forcing、把答案从专家上下文里剔除——这三条是"消融可信"的最低门槛。很多论文的消融不可信，就是因为关掉一个项之后，其他项的权重悄悄变了。

再说局限：八条，按严重程度排

  1. 全文的支点是一个 0.001 的差，而它只有一个训练种子。"两条通道单独使用等价"这个结论，建立在 0.600 vs 0.601 上。作者自己在 Limitations 里写：算力限制导致每个条件只跑了一次训练，训练种子带来的方差没有被测量。
    827 场景 × 5 rollout 的 bootstrap 区间只覆盖评测方差，不覆盖训练方差。而训练方差在这个量级上通常远大于 0.001。换句话说：全文最关键的那句话，是在误差棒之外说的。
  2. 提升闭环性能的代价是碰撞率上升，而这一点在摘要里一个字都没有。作者在 Discussion 里承认：带 token 监督的耦合式分段训练，at-fault 碰撞率更高，尽管路测通过率更高或持平。
    "+17% / +40% route progress" 是这篇论文被引用的方式，但它是用安全换来的。在一个动辄讲"具身智能要上路"的领域，把安全指标藏在附录表格里、只在讨论段一句带过，这个取舍值得被点名。
  3. "保护 VLM 能力"这件事根本没被测。绝缘的唯一动机是别破坏预训练能力。而论文测的只有"驾驶理由质量"（Lingo-Judge 通过率）——这是能力的一个很窄的切面。通用 VQA、指令跟随、世界知识、长上下文推理，一个都没测。
    作者自己也承认："这不能建立更广泛的 VLM 能力保持"。但摘要的语气是"绝缘作为默认配方受到挑战"，读者会以为"保护"被证伪了。实际被证伪的是"在已有的共训配方上，绝缘提供额外保护"，而不是"绝缘不保护能力"。这两句话差得很远。
  4. 开环 ADE 与语言质量会反向，而论文拿 ADE 当主要证据。分段训练里，token 关时绝缘的 ADE 更差、理由质量反而更好（63.0 vs 61.3）。这直接说明两个指标测的不是一件事。
    更麻烦的是：开环和闭环的排序也不一致。并发 + token 开，开环几乎打平（绝缘甚至略优）、闭环差 17%（0.600 vs 0.703）。既然开环不能预测闭环，那用开环 ADE 做大多数消融，就只是在测"轨迹拟合得像不像"。论文的主要证据链，建立在一个它自己证明不可靠的代理上。
  5. "两条通道可替代"只在低带宽任务上成立，而这恰好是限定而不是普适。驾驶：0.600 vs 0.601，完美等价。操作：耦合 + 无 token（32.9）比绝缘 + 有 token（19.5）高 1.7 倍，MolmoAct2 上是 36.5 vs 22.0（1.66 倍）。
    所以正确的表述是：在动作可以量化为少数平滑标量的任务上，token 通道够用；在接触丰富的任务上，它不够用。作者把操作实验写成"同样成立"，其实它是对"可替代"的限定——而且这个限定正好指向具身智能最值钱的那类任务。
  6. 有一格方向是反的，但被一句"训练顺序只改变幅度"盖过去了。VLM 先 + token 开：绝缘 0.648、耦合 0.646——耦合略低。而作者的核心主张是"耦合更好"。
    他们确实写了"有监督时，VLM 先之后耦合几乎没有差别"，措辞是准确的；但结论段仍然写成了"耦合在两种设置下都提升"。一个 2×2×3 = 12 格的设计里，出现 1~2 格反向是正常的；不正常的是把它平均掉、不再追问"为什么这一格反向"。而这一格恰恰是最接近工业配方的那一格（π0.5 就是 VLM 先）。
  7. 只有一个驾驶基座，而且是 2B。Qwen3-VL-2B 的语义能力本来就有限，"保护它"的收益天然低。换成 7B / 72B 的多模态模型，动作梯度对语义特征的破坏可能真的更大——"绝缘不该做默认"这个结论，很可能与模型规模绑定。
    这和我们前几天拆过的那篇架构复盘是同一类陷阱：在小模型上测出来的"某机制无用"，到目标规模可能翻转。作者没有做任何规模扫描，也没有讨论这个方向。
  8. 它是纯实证，没给机制。作者自认："我们刻画了交互，但没有建立造成性能差异的机制。"而"两条通路送同一个信号"本身是一个机制断言——它需要的证据是表征层面的（比如 VLM 的表征在两种条件下的相似度、动作相关信息在哪些层被编码、探针能不能从 K/V 里读出未来轨迹）。
    现在的证据是"行为上等价"，而"行为上等价"也可能来自完全不同的原因（比如两条路都只是让 VLM 学到了"注意路面"这种粗特征）。结论可能对，解释是猜的。
一个必须说的交叉点。我们昨天拆的那篇文章讲的是"大脑和双手之间的接口"：用文本/代码通信，换大脑不用重训手；用 embedding 通信，换大脑就得重训手。
这篇论文补上了第三种状态：用 embedding 通信、但允许梯度回传。这时候大脑和双手不是"契约关系"，是共生关系——接口没有独立语义，两边的参数互相塑造。
而"绝缘"，本质上是想把一个 embedding 接口强行降级成只读契约：VLM 写、专家读，专家不许回写。实测的代价是闭环 17%（0.600 → 0.703）。
所以那句"接口决定可替换性"可以再补一句：接口也决定效率。想要可替换性，就得接受接口变窄；想要效率，就得接受两边焊死。这才是这两篇文章合起来给出的、真正可操作的那句话。

一句话总账

这篇论文的贡献不是"绝缘错了"，而是把一个捆绑销售的设计决定拆成了两个独立开关，并给出了一张能直接读的四格表。它证明的最硬的一件事是：在已经有动作 token 监督的配方里，额外屏蔽专家梯度几乎不带来保护，却要付闭环性能的代价——"重复投保"这个词，比"绝缘"准确得多。

它最该被追问的是另一头：保费收了，理赔记录是空的——但那可能只是因为从来没人报过案。论文只在一项语言指标上验证了"能力没被破坏"，而"保护预训练能力"是绝缘存在的唯一理由。在通用 VLM 能力被真正测过之前，"绝缘不该做默认"应该读成"绝缘的默认地位缺乏证据"，而不是"绝缘有害"。这两句话的区别，决定了下一版配方该怎么改。
