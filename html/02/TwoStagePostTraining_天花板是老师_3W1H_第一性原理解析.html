💡 第一性原理核心立论

多教师蒸馏看起来很划算：把一堆专家会的东西灌进一个模型。但它有个结构性天花板——你拟合的是老师的速度场，而「任务成功」不是速度场的函数。老师在某个状态只走过一条路，你学得再像，也只是复制它的水平。这篇论文分两阶段：先用蒸馏把专家能力快速并进来，再用强化学习去撞那个天花板。难点是奖励太稀疏，于是它把老师在失败轨迹上的稠密指导当成补课——成功的回合不碰，失败的回合才请老师。五个设置全部超过教师聚合成功率，厨房任务高出 12.83 个点，而且用一半的环境步数就赢过直接强化学习。

What是什么：把「整合专家」和「超过专家」拆成两件事，分两次做

这篇要解决的问题很具体：你手上有一堆按任务训好的专家，想合成一个多任务模型，还要比每个专家都好。现有三条路各有硬伤——监督微调会把示范里没有的状态留成盲区；强化学习能自己探索，但奖励稀疏，且多任务下各任务进步速度不一致；多教师蒸馏能把专家并进来，但它本质是「模仿」，模仿的上限就是被模仿者。

它的做法是把这件事拆成两段，用同一个底座串起来：

  • 阶段一 MOPD（多教师在线策略蒸馏）：让模型自己在环境里跑，跑出来的状态交给对应任务的冻结教师打「速度标签」，模型去拟合。关键在「自己的状态」——不是拿示范喂它，所以不会出现分布失配。
  • 阶段二 教师引导的 RL：在阶段一的检查点上继续，用 PPO（配 Flow-SDE 采样）拿环境奖励优化；同时只在失败轨迹上叠加教师蒸馏，成功轨迹不加约束。

Why为什么：三条路各有硬伤，而硬伤都在「目标函数选错了」

矛盾一：SFT 学的是示范的分布，部署时走的是自己的分布

监督微调的损失是在示范数据上算的。但模型一旦上环境，它访问到的状态就不再属于示范分布——一个小偏差会把机器人带到示范里从没出现过的位置，那里没有标签可学，误差开始滚雪球。这不是数据不够多的问题，是「训练分布 ≠ 部署分布」的结构性问题。加数据只能推迟它，不能消除它。

矛盾二：RL 的目标是对的，但信号太稀

强化学习直接在「任务成功」上优化，方向完全正确。可是多任务下它有两个毛病：奖励稀疏导致信用分配困难（几十步动作里不知道哪一步做对了），各任务学习进度不均衡（有的任务早就满分，有的还在零）。合在一起训，梯度会被已经学会的任务占满。

矛盾三：蒸馏的目标是「像老师」，不是「把事做成」

这是全文最关键的一句诊断：降低蒸馏误差并不等于提高闭环成功率。老师在某个状态给出一个速度，那是它自己的策略在那个状态下的取值；你把速度拟合得再准，也只是复制了它的行为，而不是复制了它的结果。更麻烦的是多教师还会打架——不同教师对共享参数产生冲突更新，某些任务提升的代价是另一些任务下降（这就是 GR1 的 Articulated 从 52.00 掉到 45.33 的原因）。

还有一个被很多人忽略的技术障碍：流式模型没法像语言模型那样逐 token 匹配分布。自回归模型的在线蒸馏很直接——每个位置对齐下一个 token 的概率分布就行。但流匹配模型是通过积分一整条速度场来生成连续动作块，中间没有「词」可以对。所以它必须先把确定性 ODE 换成随机 SDE，让每一步变成一个高斯转移，才有「分布」可比。这个转换不是技巧，是方法能否成立的前提。

How怎么做：四步，从「拟合速度」走到「只在失败处补课」

第 1 步：先认清预训练在干什么——它在回归一个速度场
流匹配的生成过程是一条常微分方程：从高斯噪声出发，沿着模型预测的速度场积分若干步，落到动作块上。训练目标就是条件流匹配：把噪声和真实动作线性插值出一个中间点，让模型预测「从噪声指向动作」的那个速度。这一步没有任何新东西，但它是后面所有推导的地基——因为速度场是可加的、可差的，才能谈「教师的速度减学生的速度」。
第 2 步：阶段一——用「自己的状态 + 老师的答案」做蒸馏
每一轮，模型在自己的策略下用 ODE 采样出轨迹，把中间的去噪状态记下来，然后在这些状态上请对应任务的教师给出速度，用均方误差拟合。两个细节决定成败：① 对去噪状态做 stop-gradient，不让梯度顺着去噪链回传（否则雅可比连乘会让训练极不稳定）；② 教师的监督因此只改「当前这一步往哪走」，不改「早期去噪步把点放在哪」。结果是：模型在自己的分布上学，但学的是老师的判断。这正是它比 SFT 快的原因。
第 3 步：阶段二——把 ODE 换成 SDE，让「像不像老师」变成一个 KL
关键转换：给 ODE 加一个与时间相关的高斯噪声项，得到 Flow-SDE。加噪声不是为了让探索更随机，而是为了让每一步转移变成一个「有均值和方差的高斯分布」——有了分布，才能算散度。然后有个漂亮的结果：因为学生和教师的转移共享同一个协方差，速度差的均方误差正比于两者转移分布的 KL 散度。也就是说，「拟合速度」和「匹配分布」在这个设定下是同一件事，只差一个与噪声尺度有关的系数。这一步把自回归蒸馏的直觉平移到了连续生成上。
第 4 步：失败门控——成功的不碰，失败的才请老师
联合目标就三项：PPO 的策略损失、价值损失、以及乘上「1 减成功标志」的蒸馏项。成功能拿到的回合，蒸馏项直接归零；只有失败的回合，老师的稠密指导才生效。为什么这么设计？因为老师的水平就是天花板，你对已经成功的轨迹继续施加教师约束，等于把刚撞开的天花板又压回去。消融印证了这一点：不加门控（全样本蒸馏）早期学得更快，但随后进入平台期，最终低于失败门控。它买的是后期，不是前期。
一句话把两阶段的分工说清：阶段一解决「怎么快」——用教师的稠密监督替代稀疏奖励，把 2000 万步压缩到 160 万步；阶段二解决「怎么高」——用环境奖励突破教师上限，教师只在卡住的地方扶一把。缺了阶段一，阶段二变成又慢又难的直接 RL；缺了阶段二，模型只是个蒸馏出来的「平均值」，永远到不了教师之上。

Formula核心公式：四个式子，从速度回归走到「失败才补课」

① 条件流匹配：预训练到底在拟合什么
\[ \mathcal{L}_{\mathrm{CFM}}(\theta) = \mathbb{E}_{(c,a),\,\epsilon,\,u}\Big[\ \big\|\, v_{\theta}(z_u,u\mid c) - (a-\epsilon) \,\big\|^{2}\ \Big],\qquad z_u=(1-u)\epsilon+u\,a \]
\(c\) 是观测条件（图像 + 语言 + 本体感觉），\(a\) 是真实动作块，\(\epsilon\) 是高斯噪声，\(u\in[0,1]\) 是插值系数，\(z_u\) 是噪声与动作之间的中间点。大白话：在噪声和动作之间随便取一个点，问模型「从这里往动作那边该走哪个方向」，标准答案就是「动作减噪声」。注意目标不是「动作」而是「方向」——这正是它能和后面教师的速度直接相减的原因。
② 阶段一的蒸馏损失：在自己的状态上，学老师的判断
\[ \mathcal{L}_{1}(\theta) = \sum_{k=1}^{K}\alpha_{k}^{(1)}\,\mathbb{E}_{\mathcal{B}_{k}(\mathrm{sg}[\theta])}\Big[\big\|\, v_{\theta}(\mathrm{sg}[z_j],u_j\mid c) - \mathrm{sg}[v_{T_k}(z_j,u_j\mid c)]\,\big\|^{2}\Big] \]
\(T_k\) 是第 k 个任务组的冻结教师，\(\mathrm{sg}[\cdot]\) 是停止梯度，\(\mathcal{B}_k(\mathrm{sg}[\theta])\) 表示采样分布来自学生自己的策略。大白话：轨迹由学生自己跑（所以不偏离自己的分布），标签由老师来打（所以有稠密监督）。两个 stop-gradient 是保命的：一个堵住「通过改早期去噪步来移动监督点」的作弊路径，一个让教师永远是个不会动的靶子。
③ 阶段二的蒸馏项：一个「速度差」等于一个 KL
\[ \ell_{\mathrm{SDE}}(\theta) = \frac{\Delta u_j}{g(u_j)^{2}}\Big(1+\frac{u_j\,g(u_j)^{2}}{2(1-u_j)}\Big)^{2}\,\big\|\, v_{\theta}-v_{T_k}\,\big\|^{2} \;=\; \frac{2}{D}\,D_{\mathrm{KL}}\big(p_{\theta}^{j}\,\big\|\,p_{T_k}^{j}\big) \]
\(g(u)\) 是噪声调度，\(\Delta u_j\) 是离散步长，\(D\) 是动作维度，\(p^j\) 是第 j 步的高斯转移。大白话：左边是「速度差乘一个随时间变化的系数」，右边是「两个高斯分布之间的 KL」。等号的意义：你以为你在做回归，其实你在做分布匹配。系数 \(\big(1+u g^2/2(1-u)\big)^2\) 说明越靠近生成末段（u→1），同样的速度差被放大得越厉害——也就是末段那几步最不能错，这符合直觉：最后几步决定动作落点。
④ 联合目标：奖励 + 价值 + 只对失败生效的补课
\[ \mathcal{L}_{2}(\theta,\phi) = \mathbb{E}\big[\ell_{\mathrm{PPO}}(\theta)+c_{V}\ell_{V}(\phi)\big] + \beta\sum_{k}\alpha_{k}^{(2)}\,\mathbb{E}\big[(1-S)\,\ell_{\mathrm{SDE}}(\theta)\big] \]
\(S=1\) 表示该回合成功，\((1-S)\) 就是失败门控掩码，\(\beta=10\) 是蒸馏强度。大白话：成功的回合只受「把事做成」的奖励驱动，失败的回合额外接受老师的指导。这个式子里最值钱的是那个 \((1-S)\)——它把「教师的角色」从「模仿对象」改成了「卡住时的助推器」。而 \(\beta\) 的敏感性也在这里暴露：β=100 时早期涨得快但后期平，β=1000 直接过早饱和——老师扶得太多，学生就学不会自己走。
⑤ PPO 的概率比：用 SDE 的高斯密度算，而不是用 token 概率
\[ r_{\theta} = \frac{p_{\theta}^{j}(z_{j+1}\mid z_{j},c)}{p_{\theta_{\mathrm{old}}}^{j}(z_{j+1}\mid z_{j},c)},\qquad \ell_{\mathrm{PPO}} = -\min\big(r_{\theta}\hat{A},\ \mathrm{clip}(r_{\theta},1-\epsilon,1+\epsilon)\hat{A}\big) \]
\(\hat{A}\) 是广义优势估计，\(\epsilon=0.2\) 是裁剪范围。大白话：PPO 需要知道「新策略产生这个动作的概率比旧策略大多少」，自回归模型直接读 softmax 就行；流式模型没有 softmax，所以只能借 SDE 每步的高斯密度来算这个比值。这就是「把连续生成改造成可做 RL 的形式」的全部秘密——也是这类方法最脆弱的一环：概率比依赖噪声调度的选择，换一个 \(g(u)\) 结论就可能变。

Worth价值与局限：它证明了「蒸馏 + RL」不是叠加，而是接力

它真正贡献了什么

  • 把「超过教师」从口号变成了表格上的一个数。五个设置全部超过教师聚合成功率：LIBERO 98.75 对 97.25、Kitchen 75.50 对 62.67、GR1 49.83 对 49.08。这件事以前很少有人做干净——多数蒸馏工作报告的是「接近教师」，因为理论上你就该被教师上界住。它给出的破法很朴素：让另一个信号（环境奖励）进来。
  • 样本效率的对比是全文最实用的一组数。阶段一 160 万步就达到 94.8%，而直接 RL 跑 2000 万步才 89.4%——十二分之一的交互量，分数还高 5.4 个点。对做机器人的人来说，环境步数就是真机小时数或仿真机时，这个比值直接对应成本。
  • 「失败门控」这个设计有可迁移的洞察。它说的其实是一件更普遍的事：专家指导在「你已经会了」的地方是负资产。因为专家只是众多可行解里的一个，你一旦成功，再向它靠拢就是把自己拉回它的分布。这条判断适用于任何 teacher-student 场景，包括蒸馏、包括 RLHF 里的参考模型约束。
  • 把流式模型的 RL 做通了，而且给了 KL 的解释。「速度回归正比于转移分布的 KL」这个等式不是装饰——它意味着你可以用最普通的 MSE 实现分布匹配，不必去算复杂的散度。对做 flow / diffusion 策略后训练的人，这是可直接抄的工程结论。
  • 消融设计得诚实：两项都砍掉都掉点，而且掉的方式不同。2000 万步时完整 98.7%、仅 OPD 96.4%、仅 RL 96.9%。「仅 OPD」和「仅 RL」差不多，但加起来多 2 个点——这说明它们的互补性不在「各自多强」，而在「各自补对方的短板」。

必须打的折扣

  1. 全部实验在仿真里，没有真机。LIBERO、RoboCasa 都是仿真基准，训练与评估同域。而这篇的核心主张之一是「环境奖励能把性能推过教师」——在真机上，奖励从哪来？成功判定靠什么？这个最关键的问题论文没有回答。对比同期的 VLA-MOPD 有真机评估，这是明显短板。
  2. GR1 上「超过教师」只超了 0.75 个点，而且有一个方向在退。49.83 对 49.08，这个差距在每任务 50 回合的评估噪声范围内。更值得警惕的是 Articulated 从 52.00 掉到 45.33（-6.67）。作者把它归因于多教师参数冲突，但这等于承认：冲突问题没解决，只是被其他方向的增益盖住了。
  3. β 的敏感性说明方法不稳。β=10 后期最好、β=100 早期最好、β=1000 过早饱和。三个数量级的同一个系数，行为差异这么大，意味着换数据集、换模型、换任务数量都得重调。论文没有给调参规则（比如按成功率自适应），这是复现时最容易被卡住的地方。
  4. 失败门控依赖二元成功信号，而真实任务常常是「部分成功」。倒水倒了一半、装配到位但没锁紧——这些回合算 S=0，会被当成完全失败去接受教师的全量约束，可能把已经做对的部分也拉回教师的行为。论文没有讨论这个信息损失，也没有软性成功度量的版本。
  5. 教师是按任务组手工划分的，分组策略的影响没被分析。RoboCasa 的任务分组由人工按相似性划分，每个任务组配一个教师，权重 α 也是设定的。「分几组、怎么分」对结果的影响完全没有消融——而这在多教师蒸馏里往往比算法本身更影响成绩。
  6. 推理成本没提，但代价可能不小。训练要 8 张 H100、要额外训一个价值网络、每轮还要跑教师前向。论文报的是训练侧成本，没有报部署侧——不过按设计，推理时只有学生，所以这一点算过关。真正的问题是：它冻结视觉语言主干只训动作模块，这意味着上限被主干锁死了。
  7. 训练长度受限，长期行为未知。Kitchen 的曲线在数千万步内趋于平台，图里特意省略了 7000 万到 1.3 亿步的区间。省略本身不是错，但它让「会不会后期崩」这个问题无法回答。而 RL 后训练后期崩溃是常见现象。
  8. 它是「后训练」，不是「预训练」。所有成绩都建立在已有的多任务 SFT 检查点上（GR00T N1.5、QwenVLA、π0.5）。换句话说，它解决的是「最后 2 个点怎么拿」，不是「从零怎么训」。把它读成「VLA 训练新范式」会高估它；读成「多任务后训练的标准配方」才准确。
一句话总结：它没有让蒸馏变强，它给蒸馏配了一个能推翻它的上司。最值得带走的是两条判断：① 模仿的上限是被模仿者，想让模型超过老师，必须有第二个不来自老师的信号；② 专家指导要用在卡住的地方，用在你已经成功的地方就是往回拽。而它留下的最大空白也很清楚：这套「环境奖励」在仿真里免费，在真机上昂贵——真机上的奖励从哪来，才是这条路能不能落地的真问题。
