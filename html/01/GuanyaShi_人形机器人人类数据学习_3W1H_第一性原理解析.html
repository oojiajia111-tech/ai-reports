💡 第一性原理核心立论

人形机器人卡住的不是"数据太少"，而是可扩展性和具身差距互为代价：越容易大规模采的（互联网视频），越不含底层动作；越贴身的（遥操作），越采不动。破局的唯一出路是把人类动作当"意图"、把机器人身体当"执行器"，中间插一层显式的物理落地——重定向保的是接触关系，不是关节位置。剩下的仿真-现实误差，用两分钟真机数据只修"执行层"，不动"大脑"。

① 是什么② 为什么③ 怎么做④ 价值与局限

What是什么：一张"人类数据 → 人形技能"的完整流水线地图

这是 CMU 助理教授 Guanya Shi（LeCAR Lab，兼 Amazon FAR 团队）的一场综述式报告。它不讲单个模型，而是把"人形机器人怎么学会干活"拆成两条主线，把团队近几年十几个项目串成一条演进链：

  • 主线一·数据（预训练）：人类数据怎么"装进"机器人身体里。依次是 H2O（动作重定向 + RL 跟踪）→ HDMI（人-物联合重定向）→ OmniRetarget（保住交互关系的重定向，ICRA 2026 最佳论文）→ Spatter（动力学层面的重定向）→ EADP（把 UMI 人类数据落地成人形动作）；
  • 主线二·适应（后训练）：怎么用真实世界经验持续变强。依次是 ASAP（残差动作模型补仿真裂缝）→ FADA（拆成规划器 + 逆动力学，2 分钟真机数据微调）→ PLD（在强基座上只学小残差策略做真机 RL）→ 人类在环 RL（每任务 20 分钟，接管率 11% → 0）→ Coding Agent（ENPIRE 直接在真机上跑自动实验，SimEx 用"代码策略"迁移）。

对照物是语言模型：大规模预训练 + 后训练（RLHF / RLVR）。报告的核心提问就一句：这套配方能不能搬到人形机器人上？答案是"能，但两个环节都得改"——因为机器人没有廉价的数据，也没有可以随便重置的沙盒。

数据谱系（越左越好采、差距越大 → 越右越难采、差距越小）：
互联网视频 → 第一人称视频 → 可穿戴设备 → UMI / UMI++ → 机器人自身数据

Why为什么：五个不能再往下拆的公理

公理一：机器人数据的采集成本，随"接触复杂度"指数上涨

遥操作要复刻场景：教机器人爬楼梯，难道给操作员也搭一套一模一样的楼梯？教它搬箱子，难道给他一个同样重的箱子？凡是涉及力交互的任务，采集就变成"复制一个世界"。再加上人形有几十个自由度，状态-动作空间比夹爪大一个量级——所以人形数据不是"少一点"，是"结构性稀缺"。

公理二：人类数据只说"做什么"，从不说"你的身体怎么做"

这是具身差距（embodiment gap）的定义：一段人手拿杯子的视频，包含了意图、时序、物体关系，唯独不包含"你的 29 个关节该怎么转、用多大力"。它是任务的上界说明，不是动作的下界标签。任何"直接拿人类视频训动作"的做法，都在偷偷假设这个差距为零——而它不为零。

公理三：可扩展性与具身差距是一对守恒量，没有免费的午餐

越靠"人类随手就能产生"的数据，规模越大、物理信息越稀薄；越靠机器人自己采的数据，物理信息越全、规模越死。所以正确的问题不是"哪种数据最好"，而是"用哪一种数据补哪一段信息"——这决定了整条流水线的形状。

公理四：人和机器人之间真正该保住的，是"关系"，不是"位置"

人身材和 G1 身材不一样，硬对齐关节角或末端坐标，手就会"看起来碰到、实际没碰到"（报告里叫虚构接触）。而任务能不能成，取决于"手压在箱子上沿、重心在脚掌投影内"这类相对关系。所以重定向的目标函数应该定义在图（人体各部位—物体表面点）的关系结构上，而不是欧氏距离上。

公理五：仿真-现实差距可以按"层"切开，切开后就只需要小数据

误差分成两层：意图层（该干什么——规划器基本能对）与执行层（这具身体怎么干——差得多）。只要承认这个分层，适应就退化成"冻结大脑、只微调小脑"，从"重训整个策略"降级为"2 分钟监督学习"。同理，真机 RL 也不必从零学，只需在强基座上补一个小残差——这是 PLD 和人类在环 RL 能省下几个数量级成本的全部原因。

How怎么做：一条"重定向 → 落地 → 适应 → 自动化"的流水线

A · 数据侧：把人类动作"翻译"成机器人动作

Step 1 · 运动学重定向（H2O 的老配方）
第一步把人的动作改写成机器人能做的动作，顺手剔掉"人能做、机器人做不到"的部分；第二步用强化学习训一个运动跟踪策略，再迁到真机。这套两步法今天已经是社区标准。
Step 2 · 人-物联合重定向（HDMI）
不只重定向人，同时重定向物体，得到"人体轨迹 + 物体轨迹"的联合轨迹，再让策略去跟踪。这一步把"搬箱子"从纯运动问题变成交互问题。
Step 3 · 保关系的重定向（OmniRetarget，本报告的主角）
在物体表面随机撒点，按"人体哪一部位碰了物体哪个点"建一张交互图；对目标机器人 + 物体再建一张。然后优化，让两张图的拉普拉斯表示尽量接近——约束里塞进穿透、关节限位、平滑、支撑脚。妙处在于：重定向一准，后面 RL 就变简单，一套标准奖励函数通吃所有任务，不用逐任务调参。
交互保真重定向（按报告描述还原的目标形式）
\[ \min_{\mathbf{q}_{1:T}}\;\big\|\,\mathcal{L}\!\left(G^{\text{human}}_{\text{contact}}\right)-\mathcal{L}\!\left(G^{\text{robot}}_{\text{contact}}(\mathbf{q}_{1:T})\right)\big\|^2 \;+\;\lambda_1\underbrace{\mathcal{C}_{\text{pen}}}_{\text{不许穿模}}+\lambda_2\underbrace{\mathcal{C}_{\text{lim}}}_{\text{关节限位}}+\lambda_3\underbrace{\mathcal{C}_{\text{smooth}}}_{\text{别抖}}+\lambda_4\underbrace{\mathcal{C}_{\text{foot}}}_{\text{脚别飘}} \]
说人话：\(\mathcal{L}(\cdot)\) 是图的拉普拉斯矩阵，它只记"谁和谁挨着、挨得多紧"，不记绝对坐标。所以优化它等于说——你的胳膊短一点没关系，但你手压在箱沿上这个关系必须还在。后面四个 \(\mathcal{C}\) 是工程护栏：别穿模、别超关节、别抖、脚要在地上。
Step 4 · 动力学层面的重定向（Spatter）
运动学重定向只管"姿势对不对"，不管"力气够不够"。Spatter 干脆把它写成最优控制问题，用采样法解，直接在动力学层面重定向——所以能开环回放就完成拧灯泡、拔充电器这类灵巧手任务（前提是初始状态必须严格对齐）。
Step 5 · UMI 数据的落地（EADP）
手持设备采的数据差距更小，但仍假设"底层控制器足够理想"。EADP 只改扩散策略里的一个环节：把"高层动作块"和"低层控制器实际跟踪结果"的误差算出来，用分类器引导的方式把这个误差的梯度塞回去，让生成的动作块天生"好执行"。零机器人数据，纯人类数据学成插灯泡。

B · 适应侧：用真实经验持续变强

Step 6 · 补仿真裂缝（ASAP）
仿真里训好策略 → 真机跑一遍收轨迹 → 把真机动作放回仿真跑，得到仿真轨迹 → 二者有差，就学一个残差动作模型：输入状态、动作、少量历史，输出"该在动作上加多少"使仿真轨迹贴近真机。把残差固定住，再回仿真重训策略。单腿站立、后仰跳投这些演示就是这么来的。
残差动作模型（ASAP 的直觉形式）
\[ \pi_{\text{sim}}\!\big(s,\;a+\Delta_\phi(s,a,h)\big)\;\approx\;\pi_{\text{real}}(s,a),\qquad \phi=\arg\min_\phi\;\big\|\,s^{\text{sim}}_{t+1}-s^{\text{real}}_{t+1}\,\big\|^2 \]
说人话：真机和仿真之间差的那一点点，固定成一个"补丁" \(\Delta_\phi\)。以后在仿真里执行 \(a+\Delta_\phi\) 就等于在真机执行 \(a\)。所以策略可以在仿真里放心练，练出来的动作自带补丁。
Step 7 · 拆开再修（FADA）
ASAP 的毛病是每次都要"学残差→回仿真重训"一轮，太慢。FADA 把策略切成 Planner（预测未来一段感知意图）+ IDM（意图→动作块）。部署时冻结 Planner，只用约 2 分钟真机数据监督微调 IDM。直觉很硬：仿真的主要误差不在"该干什么"，而在"怎么干"。注意 Planner 必须靠 DAgger + 已训好的 IDM 一起训，单独监督学不出来。
Step 8 · 只学残差（PLD）与人类在环 RL
基座够强时，真机 RL 只学一个极小的残差策略：视频里绝大多数时刻残差输出≈0，只有当基座插 GPU 出现偏差时才出手修正。人类在环更进一步：机器人自己跑，卡住了人用 VR 接管，接管段给高奖励、失败段给低奖励，每轮用 IQL 学 Q、AWR 更新策略。每任务约 20 分钟真机数据即可，六项任务成功率全部 > 80%，接管率从第一轮 11% 掉到第四轮≈0。强化学习还顺带教会了"失败重试"——因为它能做信用分配，行为克隆很难学到这个。
Step 9 · 让 Agent 自己跑实验（ENPIRE / SimEx）
最后一个问题最扎心：数据、策略、评估都自动了，跑实验的其实还是实习生。ENPIRE 让 Coding Agent 直接操作真机：它自己写每任务的真机 Gym（reset、reward、obs、state 四件套），自己调用 SAM / YOLO 做成功判定，自己提出"加演示数据、加 BC 正则、调 batch size、补控制器"这类改进，三四小时把成功率从≈0 拉到接近 100%。难点不在算法，在安全护栏。SimEx 则让 Agent 产出"调用 IK / MPC / 阻抗控制的代码策略"，在仿真里练流程、在真机里只花约 10 分钟适应——它迁移的是工具使用知识和执行流程，所以仿真不准也能成（折布这种软体任务照样过）。

Worth价值与局限：一份"工程现状报告"，不是一份"通用智能宣言"

价值一：把"数据焦虑"翻译成了可操作的问题。不再争论"人类数据够不够用"，而是画出一条谱系，明确每种数据补哪段信息、缺哪段信息。这是能直接指导采数预算的框架，比任何单点 SOTA 都实用。
价值二：指出"适应"可以从重训降级为微调。FADA 用 2 分钟数据、人类在环用 20 分钟数据就能拿下任务，意味着人形机器人落地成本的大头从"训练"变成了"采几十条轨迹"。这直接改变了商业模型。
价值三：Coding Agent 重估了仿真的价值。"仿真必须足够准"这个信条被松动了——如果迁移的是流程和工具知识，粗糙的仿真也有用。这可能是 Real-to-Sim 第一次找到经济上说得通的落点。
局限与冷思考：
  1. 全链路的"标准答案"还没出现。报告自己承认两个开放问题没解：怎样在最高可扩展性下把具身差距压到最低；异构人类数据与机器人数据到底该怎么联合训练。目前全是经验配方。
  2. 演示环境离家庭还很远。抓箱子搬到第八次电机过热、沙地跳舞、梯子攀爬——都是实验室强约束场景。真实家庭的长尾（透明物体、软物体、杂物堆）没被覆盖。
  3. 依赖"初始状态严格对齐"的开环回放不能当能力。报告里明确解释过：开环能成是因为初始状态一致 + PD 目标本身有柔顺性，这不是策略的鲁棒性，别误读成成功。
  4. 数据质量 > 数据数量的判断，反过来打脸"堆视频"路线。讲者直言：三百万小时缺物理信息的第一人称视频，很可能就是垃圾进垃圾出。这对当前"视频预训练万能论"是一记冷水。
  5. Agent 自动实验仍要人搭台。ENPIRE 必须人来设计真机 Gym 与安全框架、还要喂初始演示；它把"跑实验的人"换成了"设计环境的人"，不是零人力。

一图速记

一句话版本：人类数据给意图、重定向给身体、残差给物理、Agent 给流程——四层各补一段差距，人形机器人才从"会跳舞"走到"会干活"。

三句话记住：① 数据的可扩展性与具身差距是一对守恒量，别再找"完美数据"；② 重定向的目标是保住接触关系，不是对齐关节位置；③ 适应的正确姿势是冻结大脑、只修小脑，2 分钟真机数据就够。
