💡 第一性原理核心立论

这是一份按个人兴趣排的阅读清单，不是质量榜；但它无意中画出的是当前具身智能的产线图。五个标签——策略的强化学习微调、世界模型与世界动作模型、VLA 与通用策略、大规模人类视频、模仿学习与数据质量——拼起来是同一个闭环的五道工序：先用人类视频把世界的常识灌进去，再把常识接到动作上，然后用世界模型当廉价试错场，用进度奖励当不靠人写规则的裁判，最后用强化学习把成功率推过部署线。判断一篇论文的分量，看它替换的是这五道工序里的哪一道，而不是看它刷了哪个榜。

What是什么：一份"用模型筛出来的"会议阅读清单

CoRL 2026 在 Austin 接收了 687 篇论文。作者所在的课题组一个人都读不完，于是他做了一件事：用自己的研究兴趣当先验，把论文排序，保留前 101 篇，并分成三档——P0 必读 26 篇、P1 应读 45 篇、P2 有余力可读 30 篇。全部 101 篇里有 11 篇 Oral、13 篇 Spotlight。

它是怎么做出来的（这一步比清单本身更像方法）

① 起点是全量元数据，不是熟人推荐
从 687 篇接收论文的标题 + 摘要出发，配上会议官方日程（Oral / Spotlight / 海报场次与编号）、社区维护的论文清单（作者 + 摘要，用 OpenReview ID 对齐）。
② 排序模型只用作者自己的语料训练
训练数据 = 他发表过的论文 + 过去六个月加进个人文献库的论文。把它们与近期 arXiv 论文、CoRL 论文作背景对比，让每篇候选都能和"一篇典型 CoRL 论文"比较。模型结构是组合拳：arXiv Sanity 风格的线性支持向量机 + TPMS 风格的相关性，也就是经典的审稿人匹配分数。
③ 人工只做后处理
前 101 篇按排名分 P0/P1/P2 → 按主题归类 → 用 LLM 按摘要起草每篇的一句话概述。作者明确交代："这份清单基于我个人的研究兴趣，而非对论文质量的评判。"

五个主题，各自的门面论文

主题P0 里最能代表的一句
策略的 RL 微调RL Token：从 VLA 里提出紧凑的"RL token"，以 VLA 为锚点在上面训一个小 Actor-Critic，做到小时级的真机 RL
RL 算法与探索Learning Object Manipulation from Scratch：交互引起的模式变化会让对比式 RL 失效，用交互加权重采样解决

Why为什么：五个主题不是五个热点，是一个闭环的五道工序

如果只看清单，会觉得 2026 年的 CoRL 在同时追五个方向。但把它们的输入输出摆在一起，会发现它们首尾相接——这不是从众，是同一个约束在五个位置上逼出来的解。

那个约束只有一句话：机器人策略要变强，必须有大量、可评估、便宜的试错。而现实世界里，这三样一样都没有——真机试错贵、慢、危险；奖励靠人写；场景靠人搭。

工序一：人类视频 → 先验（解决"见过的东西太少"）

机器人数据的量与语言数据差好几个数量级。于是转向人类视频：EgoScale 发现第一视角人类数据存在对数线性的 Scaling Law，Ego2Robot 与 Being-H0.5 直接把数万小时人类数据喂给 VLA 预训练；LAPT-Scale 与 ELA 更进一步，从视频里学潜在动作——不用动作标签，只学"画面这样变，意味着做了一个什么样的动作"。

工序二：世界模型 → 试错场（解决"试错太贵"）

有了先验还不够，策略需要"做错了会怎样"的廉价反馈。所以这一批工作把世界模型分成两种用法，对应两篇标志性论文：

当作仿真器：SafeDojo / WoVR / MERL
在想象出来的 rollout 里做 RL。SafeDojo 更具体：在交互式视频世界模型中对 VLA 做基于模型的安全 RL，用想象得到的进度奖励加一个学出来的安全预测头。它们共同的努力方向，是让"在想象中学习"变得可信。
当作策略本身：DreamZero / TAPESTRY / W2A / FACT
不预测动作再执行，而是连未来画面一起预测，动作是世界演化的副产品。FACT 特别值得注意：它让模型学错误动作会造成什么后果——这等于给"试错场"补上了负样本。

工序三：进度奖励 → 裁判（解决"奖励要人写"）

RL 最贵的一环从来不是算力，是奖励函数。稀疏的成功/失败信号在长程任务里几乎无法学习，稠密奖励又得靠人手工设计。这一批工作（WARP-RM、TOPReward、RARM）的共同目标是：不依赖手工设计，直接产生稠密的任务进度信号。这相当于把"裁判"自动化了——它输出的是"你比刚才更接近目标了"，而不是"你对/错"。

工序四：RL 微调 → 把先验推过部署线（解决"预训练不等于能用"）

这一组是今年最密集的，因为它直接决定"能不能用"。四条不同的技术路线：

论文关键手法它换掉了什么
EXPO-FT对预训练 VLA 做稳定、样本高效的真机 RL 微调换掉"微调必然崩"这个经验
RL Token提出紧凑 token，在上面训小 Actor-Critic，VLA 当锚点换掉"RL 必须更新整个大模型"
Flow Policy Gradients让 Flow Matching 的策略梯度真正可用，支持从头训与微调，两个 Humanoid 上 sim-to-real换掉"生成式策略不能直接做策略梯度"
RoboFFT用前向加噪过程 + 策略比率加权的 Flow Matching 代理目标做在线 RL换掉"扩散/Flow 策略只能靠模仿"

还有两条是"换环境"而不是"换算法"：Scaling Sim-to-Real VLA RL with Generative 3D Worlds 用生成的多样化 3D 场景做 RL 微调，避免真机 RL 里的场景过拟合；Learning While Deploying 直接把机群规模当成 RL 的并行度。而 HARBOR 想换掉的是人——一个面向 Agent 的 harness 框架，自动完成环境搭建、奖励设计、调参和 sim-to-real 训练。

工序五：数据质量与探索 → 决定这条线能重复几次

剩下那一批看起来最"不性感"的工作，恰恰决定前四道工序有没有意义。Play2Perfect 问的是多指手的任务无关探索预训练里，到底什么因素对精密装配重要；FlashRFCL 用反向—正向课程 + 高吞吐 GPU 仿真，做到只用一条示范就完成稀疏奖励 RL；Learning Loco-Manipulation from SMPC Demonstrations 用仿真里的采样 MPC 生成离线数据，让 off-policy RL 不靠奖励塑形也能学移动操作。

五道工序的因果顺序：人类视频给先验 → 世界模型给廉价后果 → 进度奖励给自动裁判 → RL 微调把成功率推过线 → 数据与探索决定这套流程能不能在自己的任务上复现一次。缺任何一道，闭环就断在那一环，而断在哪一环，看论文的"输入"就知道。

How怎么做：把清单当工具用的三种读法

读法一：按"工序"读，不按"排名"读

P0 / P1 / P2 是作者兴趣的排序，不是价值的排序。真正可迁移的信息是主题分布：五个方向里，RL 微调与 RL 算法探索合起来占了最大的两块，世界模型与 VLA 各占一块——这说明今年社区的重心是"怎么让已有策略变强"，而不是"再造一个更大的策略"。

读法二：盯"它换掉了哪个假设"

把上面那张表的方法反过来用：每篇论文真正贡献的往往不是新模块，而是推翻了一条大家默认的假设。举例——

  • RL 必须更新整个大模型 → RL Token 说只需要一个小头；
  • Flow / 扩散策略不能做策略梯度 → Flow Policy Gradients、RoboFFT 说可以；
  • 奖励必须人写 → WARP-RM / TOPReward / RARM 说可以让模型给稠密进度；
  • 世界模型必须用成功数据训练 → Training Controllable World Models 反过来指出：只用成功数据训练的世界模型会忽略动作——这条负面结论比很多正面成果更值钱。

读法三：把"清单方法"本身当成可复用的工具

作者的做法其实是一个可复制的小系统：你的发表 + 你的文献库 → 训一个轻量排序器（线性 SVM + 审稿人匹配分数）→ 对全量候选打分 → LLM 按摘要写一句话。它的成本极低（687 篇全量元数据），产出是"一个和你兴趣对齐的漏斗"。任何一个课题组都可以用同样的方式，把自己领域的会议变成一份 50 篇以内的可读清单。

但它有一个必须承认的代价：排序器是用"你过去读过的"训练的，所以它只会放大你已有的兴趣。作者自己也说得很清楚——许多优秀工作没进清单，仅仅因为它们不属于他所在研究组的领域。这意味着这份清单适合"跟进自己赛道"，不适合"发现赛道之外的意外"。

Formula公理链与判据

① 公理链：为什么这五道工序必然同时存在
第 1 步（目标是可控性）：我们要的不是"能生成动作"，而是"在没见过的场景里，按指令把事做成"。这是一个泛化 + 可靠的联合要求，不是单点能力。
第 2 步（泛化需要覆盖）：覆盖只能来自数据。真机数据受"机器人数 × 时间"封顶，人类视频是唯一数量级对得上的替代源 → 工序一不可避免。
第 3 步（可靠需要试错）：可靠性要靠大量失败来磨，而真机试错贵、慢、危险，所以必须有更便宜的后果模型 → 工序二不可避免。
第 4 步（试错需要信号）：没有奖励，试错只是随机游走；稀疏奖励在长程任务里学不动，稠密奖励要人写 → 自动稠密奖励（工序三）不可避免。
第 5 步（信号需要落到策略上）：预训练策略的分布与"高成功率"之间有一段距离，把这段距离走完就是 RL 微调（工序四）；而这段距离每换一个任务就要重走一次，所以数据与探索效率（工序五）决定复现成本。
结论：五个主题不是五个热点，是一个联合要求被拆成五段后，每段的工程化。这也解释了为什么它们在同一年一起爆发。
② 世界模型当仿真器的前提：动作必须"能被听见"
\[ \hat{s}_{t+1} \sim p_\theta\big(s_{t+1} \mid s_t, a_t\big) \quad\text{可用，当且仅当}\quad I\big(a_t;\, \hat{s}_{t+1} \mid s_t\big) > 0 \]
\(s_t\) 状态（或它的潜在表示）、\(a_t\) 动作、\(I(\cdot;\cdot\mid\cdot)\) 条件互信息。
式子在说什么：一个世界模型能不能拿来当试错场，不取决于它预测得准不准，而取决于它有没有"对动作敏感"。如果 \(I=0\)，意思是——不管你做什么，它都预测同一个未来。
这正好是 Training Controllable World Models 那条负面结论的严格版本：只用成功数据训练时，动作与未来几乎统计独立（成功轨迹都长一个样），模型于是学会"忽略动作"，RL 在里面的梯度是零信息。
工程判据：接一个世界模型做 RL 之前，先做一次"反过来测"——固定状态，喂不同动作，看预测的未来有没有分开。不分开就别用，再准也没用。
③ 为什么需要稠密进度奖励（稀疏奖励的信息量问题）
\[ \mathbb{E}\big[\nabla_\theta \log \pi_\theta(a_t|s_t)\,\hat{A}_t\big] \;\;\text{在稀疏奖励下}\; \hat{A}_t \approx 0 \;\;\text{于绝大多数 } t \]
\(\hat{A}_t\) 是优势估计，\(\pi_\theta\) 是策略。
式子在说什么：策略梯度是"用优势给动作加权"。任务只有最后成功/失败一个信号时，除了最后一步，所有中间步的优势都是 0，梯度也就是 0——不是学得慢，是根本没有梯度。
这正是 WARP-RM / TOPReward / RARM 的动机：把"离目标更近了多少"变成每一步都能拿到的分数，让 \(\hat{A}_t\) 处处非零。代价是引入了一个会错的裁判——奖励黑客（reward hacking）的风险随稠密度上升，这也是"进度奖励"这条线真正的难点所在。
④ 人类视频的对数线性律：为什么它值得投
\[ \text{Perf} \;\approx\; \alpha \log H + \beta \qquad \big(\text{斜率恒定} \Rightarrow \text{边际收益递减，但永不为零}\big) \]
\(H\) 是人类数据的规模（小时数），\(\alpha,\beta\) 是拟合常数。EgoScale 报告的是这种对数线性关系。
读法：对数线性意味着每翻一倍数据带来的提升是固定的一个小量，而不是幂律那种"投入越多越猛"。它的战略含义是：这条路不会突然起飞，但也永远不会饱和——所以值得长期投入，只是不能指望它单独解决问题。
与工序二的关系：正因为人类视频的收益是对数的，剩下的差距必须靠"试错场 + RL 微调"去补——两条曲线的斜率差，就是今年这批 RL 论文存在的理由。
⑤ 泛化差距：为什么"新任务两倍于 VLA"是个强信号
\[ \text{Gap} \;=\; \mathbb{E}_{\text{新任务}}\big[R\big] \;-\; \mathbb{E}_{\text{训练分布}}\big[R\big] \]
DreamZero 声称在新任务上的泛化达到 VLA 的两倍，比的正是这个 Gap，而不是训练分布内的成功率。
为什么重要：在训练分布内刷分，靠的是记忆；只有跨分布的差距缩小，才说明模型学到了"世界怎么运作"而不是"数据长什么样"。读任何 VLA / 世界模型论文，先找它报的是哪一个数——只报同分布成功率的，泛化能力无法判断。

Worth价值与局限

核心价值：一份清单，三种用法。
① 当索引：101 篇带一句话概述、OpenReview 链接、Oral/Spotlight 场次与海报编号，还导出 BibTeX 可导入 Zotero / Paperpile。作为工程效率工具，它已经完成使命。
② 当雷达：五个主题的分布，比任何单篇论文都更能说明社区在往哪挤。今年很明显——重心在"让已有策略变强"，不在"造更大的模型"。
③ 当方法论模板：轻量排序器 + LLM 摘要这套流程，任何课题组都能在一周内复制到自己的领域。

它明确不适合被当成什么

不是质量榜：作者原话——"基于我个人的研究兴趣，而非对论文质量的评判"，"许多出色的工作没有出现在这里，仅仅是因为它们不属于我所在研究组的研究领域"。101 / 687 ≈ 15%，剩下 85% 里有大量同等质量的工作。

批判性审视

  • 排序器＝兴趣的自我复制，存在系统性盲区：训练语料是"自己的论文 + 过去六个月自己加的文献"。这类模型的输出必然向已有兴趣收敛，因此它擅长"跟进"，完全不擅长"发现"。用它当唯一的会议导航，会持续加深既有偏见——而作者的诚实说明，恰恰暴露了这个设计缺陷。
  • 一句话概述由 LLM 按摘要生成，摘要与正文的落差被继承：摘要里的"达到 SOTA"、"两倍泛化"经常在正文里有更弱的限定条件。用一句话概述当决策依据，是这份清单最容易被误用的地方——它适合筛选"要不要下载 PDF"，不适合判断"这个结论成不成立"。
  • 五个主题的划分是作者视角，不是会议的客观结构：注意 P0 里的分节其实是"RL 微调 / RL 算法与探索 / 世界模型与世界动作模型 / VLA 与通用策略 / 模仿学习与数据质量"。"大规模人类视频"和"进度奖励"在文章开头被列为独立方向，但在清单里被并进了其他分节——说明这套分类是事后整理的，不是会议的官方 track。把它当"领域地图"时要留这个折扣。
  • 缺少跨方向的横向对比：清单把 RL 微调的四条路线（EXPO-FT / RL Token / Flow Policy Gradients / RoboFFT）并列，却没有给它们的实验条件是否可比。而这四条路线在样本效率、真机时长、本体上的口径很可能完全不同，并列容易被误读为"任选一条都行"。
  • "两倍泛化"这类数字缺少口径：DreamZero 的"新任务泛化是 VLA 的两倍"是一句话概述里最亮的数字，但两倍是成功率之比、还是 Gap 之比、在什么任务集上——清单没有交代。这正是第②条批判的实例。
  • 对"世界模型当仿真器"这条线的困难描述不足：清单把 SafeDojo / WoVR / MERL 归为"让想象 rollout 更可信"，但没有指出这条线最硬的负面结果——在成功数据上训练的世界模型会忽略动作。读者容易高估"用想象做 RL"的成熟度。
