💡 第一性原理核心立论

过去几年具身数据的采集围绕机器人本体展开：本体决定了数据怎么采、动作怎么表示、能用于哪些模型。于是形成路径依赖——我们只采集机器人已经能执行的动作，再用这些数据训练机器人做更多类似的事。而人类在真实世界积累的操作经验，远远超出当前机器人能执行的任务范围。
解法是"头手一体"：DAS Ego 2.0 六摄 340° 视野负责全局观察，Dex 2.0 侧置仿生外骨骼（21 DoF 关节编码器，精度 0.2°）+ 半柔性电子皮肤（980 触点，1mm 空间分辨率）负责精细运动与接触测量，1ms 硬同步建立时间对应。但文章最重要的判断在后半段：规模不等于价值——规模化至少要同时考虑采集广度、监督密度、迁移价值三个维度。

Why为什么：本体中心的采集方式在画地为牢

路径依赖是怎么形成的

原文的提问很直接：我们是否正在用现有机器人的能力边界，限制对下一代具身数据的想象？

过去几年采集围绕机器人本体展开——机器人、机械臂、灵巧手决定了数据怎么采、动作怎么表示、能用于哪些模型。这有其合理性，但形成了路径依赖：

循环：只采机器人已经能执行的动作
倾向采集机器人已经能够执行的动作，再用这些数据训练机器人完成更多类似的任务。数据定义能力边界，能力边界又定义数据。

人类的经验远超机器人的能力

作者用拧瓶盖举例：手伸向瓶身、手指调整位置并建立接触；一只手固定瓶身，另一只手改变抓握姿态直到瓶盖松开；人还会根据物体移动、手指受到的阻力和视觉反馈不断调整。而对机器人而言：

  • 视频不一定能看清被物体遮挡的手指
  • 视频无法直接测量手与物体之间的接触
  • 即使拿到人手轨迹，还面临不同手部结构、运动范围和传感器的差异

四种数据源的信息量不对等

数据源能提供什么短板
机器人本体采集明确的动作与执行反馈采集成本高，受本体、任务环境、部署条件限制
互联网图像/视频丰富的场景与行为信息很难直接提供精确运动学和接触标签
仿真可无限扩展与真实世界的 gap
人类第一视角示范自然发生、覆盖广需要把"人类经验"翻译成"机器人可用监督"
关键判断：Human Data 正在解决的问题是——如何从人类与真实世界的交互中，获得机器人能够使用的训练信号？注意措辞：不是"如何采到更多人类视频"，而是"如何获得机器人能用的训练信号"。

How怎么做：三个技术难点与对应的工程选择

难点一：手部运动怎么测——四条路线与各自的代价

路线优势代价
视觉（关键点估计）不需复杂机械结构受遮挡、光照、视角、手物交互影响；手指被遮挡时关节状态难恢复
柔性传感（形变/电阻）对手部结构限制少材料本身形变、滑移、迟滞，读数与真实角度间需标定建模
外部磁场可测位置姿态受工作环境其他磁性材料和电磁设备干扰
外骨骼明确关节状态机械结构扩大手部几何边界，限制部分动作，并引入人体关节轴与机械轴的偏差
Dex 2.0 的选择：轻量化侧置仿生外骨骼
机械关节结构布置在手指侧面，贴合人体关节运动轴线，减少对手背、指腹、掌面等关键操作区域的占用。相比手背式设计，侧置方案为贴面拾取、掌内旋转、狭窄空间操作保留更多空间——采集者佩戴时仍能完成自然交互。自研微型磁编码器集成在仿生关节内部，直接测关节旋转角。
文章特意做的一个区分：关节测量 ≠ 完整手部姿态重建。编码器给的是局部关节角度，完整姿态和指尖空间位置仍需结合手部运动学模型计算。优势在于直接获得具有明确运动学含义的关节状态——这正是后续姿态重建、轨迹分析、跨本体重定向需要的基础数据。

难点二：接触怎么测——串扰才是真问题

关节运动只能描述手如何移动，不能描述手与物体之间发生了什么。以旋转瓶盖为例：需要持续建立接触、调整抓握力度、根据瓶盖运动状态改变施力方式。仅有关节轨迹，很难判断接触何时发生、位置是否变化、是否出现滑移。

为什么"980 个触点"不是重点，串扰才是
假设食指指腹只接触一个小物体，相邻传感单元也产生响应，模型收到的触觉分布就比真实接触范围更大；反过来，贴合不良或漂移导致漏检，模型会低估接触面积。模型无法天然区分哪些响应来自真实接触、哪些来自设备自身的形变和干扰——这不是传感器性能问题，而是监督信号质量问题。

所以全手触觉系统要同时关注三个指标：空间覆盖、接触定位、信号稳定性。半柔性结构的意义就在于此：在曲面贴合与形变稳定性之间取平衡，减少织物拉伸、滑移、褶皱带来的运动伪影，并通过传感单元与阵列结构设计降低机械和电磁串扰。

难点三：多模态怎么对齐——同步 ≠ 标定

如果视觉、关节、触觉只是分别录制、事后按文件时间戳匹配，就会受操作系统调度、通信传输、数据缓存、驱动队列影响。在快速抓取、接触点切换、插拔操作中，时序误差会让画面与动作标签无法准确对应。

Dex 2.0 与 Ego 组合采用统一时基、硬件触发和相机快门曝光控制，在采集源头规定采样时刻，实现 1ms 级时间对齐。

文章再次做了一个重要区分：1ms 级同步 ≠ 1ms 视觉时间分辨率。Ego 相机仍以 30FPS 工作，DEX 触觉 100Hz，IMU 200Hz。硬同步解决的是不同传感器时间轴之间的对应问题，不是让所有模态拥有相同的采样频率。而且——时间同步也不等于空间标定：若相机外参、手套与人体坐标关系没标准，不同模态仍无法在空间中正确对应。

最终想建立的数据结构

观察 → 动作 → 接触 → 反馈 → 调整 → 结果
视觉描述任务环境和物体状态，关节运动描述手部如何执行动作，触觉描述接触过程，后续视觉记录交互带来的环境变化。
对 VLA、VTLA 和 World Model，这种结构提供了比孤立视频或动作轨迹更丰富的监督信息——让模型有机会学习"动作如何引发接触、接触如何改变物体、反馈如何影响后续动作"。

从 Human Skill 到 Robot Skill：跨本体的真问题

人类能做的动作，不天然等于机器人能执行的。人手关节布局、运动范围、灵巧程度都与机器人灵巧手不同。即使有高精度人手关节轨迹，也不能直接作为任意机器人本体的控制指令。

TouchBridge 的 Tac-Retarget 提供了新的思路：传统运动学重定向主要匹配关节姿态或指尖位置，但指尖位置接近并不代表接触关系相同——机器人可能出现接触点偏移、接触面错位，甚至手指穿透物体。它改用接触图和指尖接触区域对齐，保留不同手型之间的接触关系。

  • 四项真实接触密集任务：人类转换数据微调 72.5%，等量遥操作数据 77.5%
  • 成功示范平均采集时间：11.7 秒 vs 81.7 秒（约快 7 倍）
  • DexWild：9,290 条人类示范 + 机器人数据联合训练，93 个真实环境，未见环境成功率 68.5%（约纯机器人数据的 4 倍），跨本体泛化提升 5.8 倍

Formula关键指标与判据

① Dex 2.0 测量指标
\[ \underbrace{21\ \text{DoF},\ \theta_{\text{err}} = 0.2^\circ}_{\text{关节编码器}} \qquad \underbrace{980\ \text{taxels},\ 1\text{mm},\ F_{\min} = 0.1\text{N},\ 100\text{Hz}}_{\text{电子皮肤}} \]
21 个独立关节编码器 / 单手；关节角度精度 0.2°；微型关节结构厚度约 3mm。
16 块触觉传感器 / 单手，共 980 个感知触点；触觉空间分辨率 1mm；最小检测力 0.1N；采样率 100Hz。
文章明确的免责：0.1N 是"最小检测力"指标，不能直接等同于压力测量误差，也不能等同于所有材料接触条件下的检测精度。980 触点和 1mm 主要描述传感阵列规格，不是端到端精度。
② DAS Ego 2.0 视野与同步
\[ \text{HFOV} = 340^\circ,\ \ \text{VFOV}_{\max} = 120^\circ,\ \ \Delta t_{\text{align}} \leq 1\text{ms} \]
六摄：2×500 万像素（核心，从上代 200 万升级，为 SLAM 定位与精细手部追踪提供更高分辨率）+ 4×200 万像素；全部 30FPS + Global Shutter；200Hz IMU；指尖追踪精度约 4mm。
关键澄清：340° 视觉覆盖 ≠ 已完成全身三维动作重建。多摄图像、IMU、指尖追踪只提供空间感知与运动估计的基础观测；获得稳定世界坐标系轨迹、全身骨骼、物体位姿，还需空间标定、视觉重建和数据处理算法。
因此 Ego 设备不应只按相机数量和像素评价——还涉及外参标定、图像时间同步、视角几何关系、头部运动与环境坐标系转换。
③ 规模化三维度判据（本文的核心框架）
\[ \text{DataValue} \neq f(\text{hours}),\quad \text{but } \text{DataValue} = f(\text{Breadth},\ \text{SupervisionDensity},\ \text{TransferValue}) \]
① 采集广度：能否覆盖更多人员、物体、任务和真实环境。
② 监督密度：能否从视频进一步获得关节、接触、物体状态和交互反馈。
③ 迁移价值：能否通过统一的数据表示和跨本体适配，让同一批人类技能被不同机器人平台使用。
反例：设备干扰了人的自然动作 → 关节标签偏离真实技能；触觉信号含大量形变与串扰 → 模型学到错误接触模式；视觉/动作/触觉无法准确对齐 → 多模态数据失去物理对应关系。这三种情况下，数据越多，模型越差。

Worth价值与局限

核心价值：本文最有价值的不是某个硬件参数，而是把"数据规模"和"数据价值"彻底分开的判据框架——采集广度 / 监督密度 / 迁移价值三个维度必须同时成立。这是一把可以直接用来评估任何数据集的尺子。附带的技术贡献是触觉作为跨本体约束的思路：不复制每个关节角度，而是保留接触点、接触区域及其相对关系。

诚实的局限（文章自己列的）

局限一：耐久性的真实表现缺长期数据
产品资料披露单片传感器可承受超 100 万次法向按压、10 万次弯折拉伸，支持 IP67。但作者明确：实际长期使用中的零点漂移、灵敏度变化、迟滞和重复性，仍需要更完整的测试数据来评价。
局限二：视觉覆盖 ≠ 动作重建
340° 视野提供的是观测条件，不是结构化数据。从原始多视角视频到可用的手部关键点、MANO 参数、深度信息，中间还有标定、跨视角关联、几何重建、任务分段一整条流水线。
局限三：跨本体仍是开放问题
人手 21 DoF 不能直接映射为所有机器人灵巧手的控制维度；人类触觉与机器人触觉的传感器布局、材料特性、受力结构并不相同，如何转成机器人可用的接触表示仍需要专门的映射和学习方法。
局限四：规模化本身有工程门槛
头戴设备的佩戴位置、头发遮挡、长时间使用中的设备状态都会影响数据质量。作者的解法是把部分检查前移到采集阶段——这说明"Human Data 能规模化"这句话本身就依赖一整套配套流程，不是买个设备就有。

批判性审视

  • 商业产品介绍与研究综述混在一起，需要分清哪些是自研、哪些是引用：Dex 2.0 / DAS Ego 2.0 是 GenRobot 自家产品（参数详尽到 0.2°、1mm、0.1N），而 EgoDex / EgoScale / VITRA / TouchScale / DexUMI / DexWild / TouchBridge 是他人工作（多数只给结论数字）。引用部分的实验细节（数据划分、基线选择）多数不可得，横向对比的可信度有限。
  • 82% vs 77.5% 这个对比要读懂：TouchBridge 的人类数据微调 72.5% 低于等量遥操作数据的 77.5%——它的优势在采集效率（快 7 倍）而非最终性能。用它替换遥操作是"省时间"的选择，不是"更准"的选择。
  • DexViTac 85%、TouchScale 57.5% 这类数字缺少基线：文章只给绝对成功率，没说"不用人类数据时是多少"。而后者才是判断人类数据价值的关键。
  • 人类触觉当"世界模型先验"是文章最激进的主张，但证据最弱：DexTouch-WM 只说"固定 5 小时机器人数据、人类数据从 0 增到 100 小时，预测持续改善"，没有给消融曲线，也没有说明"持续改善"是否收敛。
  • 1ms 硬同步 + 340° 视野 ≠ 全局三维重建——文章自己反复强调这点，但在传播中很容易被简化成"六摄 + 1ms 就能重建全身动作"，这是一个需要警惕的误读。
