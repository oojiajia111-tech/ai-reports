一句话 阶段是人造的，但「取消阶段」的收益只在很小的模型上验证过
💡 第一性原理核心立论

这篇的核心主张很漂亮：预训练、中期训练、SFT、RL 看起来是四套算法，其实都是最大似然——只是数据分布不同。既然都是似然拟合，就能合成一个目标，训练阶段这个概念就可以删掉，设计问题从「怎么排阶段」变成「喂什么数据、什么比例、什么时候喂」。数学上这个统一是成立的。但有三处必须打折：第一，摘要在说「提高了任务覆盖率」，正文 5.1.2 却写着「对于覆盖率，分阶段训练整体上具有更好的计算效率」——这是同一个指标，一正一反。第二，主实验用的是 124M 参数模型、20B token 预训练，算力约 1.5×10¹⁹ FLOPs，比 GPT-3 少 2 万倍。第三，每个配置只有 2 个随机种子。于是这篇正确的读法不是「训练范式该重构了」，而是：在一个 20000 分之一算力的沙盘上，「删掉阶段」这个方向被验证了；它在大模型上是否成立，论文没有回答，而且它自己也承认覆盖率没赢。

是什么一个 loss，一张权重表，一个异步缓冲区

传统流水线是四段，每段有独立的数据、独立的算法、独立的基础设施。论文说不必如此，因为前三段已经在做同一件事了：

阶段数据损失token 权重
预训练通用语料，prompt 为空负对数似然全部为 1
中期训练筛选语料负对数似然全部为 1
SFT指令—示范对负对数似然示范为 1，prompt 为 0
RL（MaxRL）模型自己生成负对数似然prompt 为 0，响应按通过率赋权
这张表就是全文的骨架，而且它确实漂亮。把四个阶段写成同一行「token + 权重」的格式之后，阶段之间的差别只剩一个数字：哪些 token 算数。于是「切换阶段」被降级成「改变权重分配」，一个原本需要重构基础设施的动作，变成了改一个配置。

关键一步：RL 怎么塞进似然框架

RL 看起来格格不入，因为它是策略优化。论文借助 MaxRL（Tajwar et al., 2026）的结论：二元奖励下，策略梯度可以写成对「成功条件分布」做最大似然拟合。定义 \(\pi^+\) 为「在 prompt 上成功的那些补全」的分布，则一次 RL 更新等价于对 \(\pi^+\) 做一步 MLE，并在该步内把它当固定分布。

统一目标
\[ \mathcal{L}=-\mathbb{E}_{x\sim p(x)}\ \mathbb{E}_{y\sim p^{*}_{\text{mix}}(y\mid x)}\big[\log \pi_\theta(y\mid x)\big],\qquad p^{*}_{\text{mix}}=\sum_k \alpha_k\,p^{*}_k \]
\(k\) 遍历各数据来源（静态语料、示范、RL 生成），\(\alpha_k\) 是混合权重，\(\sum_k\alpha_k=1\)。
分阶段训练是这个式子的一种特例：在任意时刻，只有一个 \(\alpha_k\) 为 1，其余为 0。
统一训练则允许所有 \(\alpha_k\) 同时非零，并随训练进程连续变化。

工程上做了什么

三件：统一数据格式（token 序列 + token 权重）、加权似然损失、一个共享数据缓冲区。生成器用近期权重产出 RL 数据丢进缓冲区，训练器从缓冲区采样，每若干步发布一次权重给生成器。数据生成和模型优化是异步的。

「异步」这两个字后面藏着一个必须付的代价，而它被放进了附录。一旦把 RL 生成的数据丢进缓冲区再采样，你拿到的就不再是当前策略产生的数据——on-policy 变成了 off-policy。论文在附录 D.6 报告了 policy staleness 和吞吐量，但正文没有任何一处说明：这种 staleness 对统一训练的优势贡献了多少，或者削弱了多少。而它是「统一」得以在工程上成立的前提条件。

为什么「阶段是人造的」这个结论有多硬

先把两件事分开：数学上的统一是真的；工程上的「不必分阶段」是另一回事。

数学部分：基本成立，但主要是引用

预训练、中期训练、SFT 都是 MLE，这没有争议。RL 那一步依赖 MaxRL 的既有结论（Tajwar et al., 2026），本文的工作是把它扩展到任意固定生成策略——即用策略 μ 生成的数据，也可以拟合它自己的成功条件分布。这带来一个实用性质：数据生成与模型优化可以解耦。作者也诚实标注了代价：这样得到的更新通常不再等价于当前策略的 MaxRL 梯度。

这一句是整个理论的地基，也是它的天花板。「不等价于真实梯度」意味着：当生成器用的是旧权重时，你优化的目标是那个旧策略的成功分布，不是当前的。这在数学上仍然是良定义的（有个明确的目标），但它不是「把 RL 变成 MLE」——它是「把 RL 换成了一个相关的、更容易优化的代理目标」。论文标题说的是前者。

它真正主张的东西，其实更小也更有意思

抛开修辞，论文实证部分真正立住的是这条：

「一种数据来源的价值，取决于它何时被引入，以及它如何与后续学习相互作用。」
这是第 7 节的原文，也是全文最扎实的发现。具体证据：
① 在预训练期就掺入中期训练数据，比「先预训练完再中期训练」保留了更多通用能力（留出损失更低，五个通用基准平均分更高）；
② 持续学习部分，统一训练的模型初始 Coding 准确率更低，但用完全相同的 Coding RL 流程训练后，最终在两个基准上都高于分阶段训练的模型；
③ 数据混合的调度（什么时候把比例降到零）会改变准确率与能力保留的权衡，而固定比例做不到这种腾挪。

这三条都比「统一训练更好」更精确。尤其是②：它说的不是「统一训练让模型更强」，而是「统一训练让模型更可教」——初始更差，后续学得更快。这是一个关于可塑性（plasticity）的主张，比关于能力的泛泛主张有价值得多。

算账摘要说覆盖率提高，正文说覆盖率输了

这是全篇最需要指出的地方。把两段话并排放：

位置原文表述
摘要「统一训练改善了准确率与计算资源之间的权衡，提高了任务覆盖率，同时保留了更广泛的模型能力」
5.1.2 正文「对于准确率，分阶段训练在中等计算预算下更具计算效率……对于覆盖率，分阶段训练整体上具有更好的计算效率」
同一个指标（pass@16 覆盖率），摘要说「提高」，正文说「分阶段更好」。这不是措辞弹性，是方向相反。摘要里漏掉的那个定语是「在泛化评估中」——原文紧接着写「在泛化评估中，统一训练的优势更加明显，几乎在所有计算预算下都取得了最高准确率和覆盖率」。

所以完整结论应该是：在训练分布内，覆盖率分阶段赢；只在泛化到更大规模谜题时，统一训练才在覆盖率上占优。摘要把这个条件删掉了。

算力差距
\[ \frac{6\times 1.75\times10^{11}\times 3\times10^{11}}{6\times 1.24\times10^{8}\times 2\times10^{10}}=\frac{3.15\times10^{23}}{1.49\times10^{19}}\approx 2.1\times10^{4} \]
主实验的算力约为 GPT-3 的 1/21000。若以今天的前沿模型（预训练 10 万亿 token 量级）为参照，差距还要再放大 1–2 个数量级。
另外，124M × 20B 意味着每参数 161 个 token，约为 Chinchilla 最优（20 token/参数）的 8 倍——这是一个刻意过训练的小模型，符合当下「小模型高 token」的潮流，但它的训练动态与大模型未必同构。
外推问题在这里不是形式主义的挑剔，而是有具体机制的理由。统一训练的优势来源是「数据复用与能力保留」——也就是减少遗忘。而遗忘强度与模型容量、训练轮数强相关：124M 模型在 510M token 上跑多个 epoch，很容易过拟合到中期数据；一个万亿参数模型在同样的数据上跑 4 个 epoch，遗忘的动力完全不同。「混着训能减少遗忘」这个结论在小模型上必然更显著，因为小模型的遗忘更严重。论文没有讨论这一点。

只有 2 个随机种子

原文写「RL 实验结果取两个训练随机种子的平均值」。Base 6000 次更新、Extended 12000 次更新，2 个种子。RL 训练的种子间方差通常远大于 SFT（生成分布随种子漂移），2 个种子的均值无法支撑「更好」这类比较级结论，而论文的关键结论全是比较级。相比之下，耗时那类可以直接测的量不需要种子——所以这里的短板恰好落在最需要它的地方。

算力分配那张图，其实对自己不利

图 5 的比较方式是：横轴为预训练 + 中期训练 + RL 的累计算力，看谁在同一预算下准确率更高。结论是「分阶段在中等预算更有效，统一在较大和最小预算更优」。这个「两头赢中间输」的形态，通常意味着两条曲线交叉了两次——而交叉两次的理由，论文没有解释。如果统一训练真有结构性优势，曲线应该整体在左上方，而不是在中间被反超。

批判六条要打折的地方

  1. 摘要与正文方向冲突。覆盖率一项，摘要「提高」，正文「分阶段更好」，差了一个「在泛化评估中」的条件。这是本文最需要修正的一处表述。
  2. 算力规模差 2 万倍，且优势机制与模型容量强相关。124M 模型上的遗忘减少，不能直接推到前沿规模——恰恰相反，小模型的遗忘更重，所以收益会被系统性高估。
  3. 2 个随机种子。所有 RL 比较结论建立在此基础上，且没有报告方差。
  4. 统一必然引入 off-policy 化，但正文没交代代价。共享缓冲区 + 异步生成 = 用旧策略数据近似当前目标。论文自己都说「不再等价于当前策略的 MaxRL 梯度」。那么「统一」买到的到底是「更好的学习信号」还是「更高的数据吞吐」？这两者在实验里没有被分开。
  5. 「阶段」并没有真的消失。第 7 节自己承认：「我们的工作并未完全消除训练阶段的概念，因为将模型适配到新的下游任务时，仍然不可避免地需要一个独立的训练阶段。」也就是说，论文推翻的是「预训练→中期→SFT→RL」这条特定流水线的必然性，而不是「训练阶段」这个概念本身。标题比结论大。
  6. 超参面变大，而不是变小。统一训练要把混合权重 \(\alpha_k\) 变成随训练时间变化的调度函数。论文自己列了开放问题：「尚未确定一种普遍适用的最佳数据混合比例或调度策略。」分阶段训练的超参是四组固定的；统一训练的超参是一条曲线。省掉了阶段切换，换来了一个连续控制问题——这不一定是净简化。

价值该拿走什么

三条可以直接用的

「一种数据该在什么时候进来」比「它占多少比例」更重要
5.2.2 的四组调度实验是最有实操价值的部分：固定比例、线性衰减、线性增长、中途退火到零。结果：中途退火能在保住 SciQ 收益的同时改善 Coding 准确率——也就是说，把某类数据「提前撤掉」，比一直按比例混着更好。这个结论可以直接搬到任何多阶段混训里，不需要接受整篇论文的框架。
预训练期掺入后期数据，能减少遗忘
这一条最反直觉也最实用：不要等预训练跑完再做中期训练，在预训练的最后阶段就开始掺，通用能力的保留明显更好（留出损失更低、通用基准更高）。代价是 RL 前的即时准确率会低一点——但 RL 之后反超了。这是典型的「先慢后快」。
评估中期训练，别看它的即时准确率
原文写得很直接：「评估 Midtraining 时，需要关注它对后续学习的支持作用，不能仅根据训练完成后的即时准确率判断其价值。」文中还给了一个反例：最终 RL 准确率最高的那组分阶段配置，在能力保留两项指标上表现最差。这对做数据配比的人是个有用的警告。

必须打折的

  • 「提高任务覆盖率」——只在泛化评估里成立，训练分布内分阶段更好。
  • 「训练阶段不是内在要求」——作者自己承认下游适配仍需独立阶段。
  • 任何「大模型上也会这样」的推论——算力差 2 万倍，且机制与容量耦合。

这篇真正的位置

它不是「训练范式重构」，而是一次把训练流水线重新参数化的尝试：把「阶段」这个离散变量换成「混合权重随时间」这个连续变量。

这个重新参数化的价值不在「统一更优」——论文自己的数据不支持这个强主张——而在它让原本不可比较的东西变得可比了：预训练的一个 token、SFT 的一个示范 token、RL 的一个成功响应，现在可以放在同一个权重向量里比较边际价值。有了这个坐标系，才谈得上「训练的科学」。

至于「阶段该不该取消」，我的读法是：不该取消，但该变成可调的。分阶段是中点，不是起点也不是终点——它对应「数据比例在某一时刻发生阶跃」这个特例。真实最优解大概率是一条平滑变化的曲线，而不是四个台阶。
