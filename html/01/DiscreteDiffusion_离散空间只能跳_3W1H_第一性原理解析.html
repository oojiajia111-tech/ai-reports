一句话 连续扩散学"往哪挪一点"，离散扩散学"这个位置要不要换"
💡 第一性原理核心立论

文本和动作 token 都是离散符号，而"离散空间里没有方向"——梯度、SDE、"朝目标挪一小步"这些连续世界的全部工具在这里直接失效，不是难做，是数学上不存在。本文的解法是把"插值路径"换成"跳变速率"：用一张率矩阵描述每个状态何时被换成另一个状态，再把它因子化到"一次只允许改一个 token"，于是生成退化成每个位置上的一个分类器。连续扩散问"往哪走"，离散扩散只问"换不换、换成谁"。

What是什么：把"扩散"这件事从连续空间搬进离散空间

先说清楚它要解决的那个具体的麻烦。我们熟悉的扩散模型和 flow matching，前提是数据点是某个欧几里得空间里的向量。你能算两个向量之差，能沿着那个差的方向走一小步，能把这个"步长"参数化成概率流——整条链路都建立在"空间里存在方向"之上。

但有一大类数据不是向量：文本是一串离散 token，DNA 是一串碱基，机器人策略里的动作如果做了 token 化，也是一串离散符号。它们的取值只能是词表里的某一个，不存在"差一点"的中间态。你不能把"抓取"这个 token 往"推"那个 token 挪 0.3 步。

最关键的一句话：离散状态空间里不存在 SDE。不是"没人写出来"，是它没有定义——布朗运动的每一步都要加一个高斯增量，而离散集合上没有"增量"这回事。所以整条 ODE/SDE 的推导工具链，在这里从第一步就断了。

本文给出的替代物是连续时间马尔可夫链（CTMC）。它是 SDE 在离散空间里的类比：不再沿着方向连续移动，而是以某个速率从一个状态"跳"到另一个状态。跳是瞬时的、无中间态的——这恰好就是离散空间唯一允许的运动方式。

于是"向量场"这个角色由 率矩阵（rate matrix）接手：一张表，写着"从状态 x 跳到状态 y 有多快"。整个框架的其余部分——条件路径、边缘路径、把条件的东西边缘化成边缘的东西、最后用一个网络去学边缘率矩阵——与连续版逐个环节对齐，只是每一样都被翻译成了离散语言。

这套东西落到具体模型上，就是现在常听到的 掩码扩散语言模型（MDLM）：把词表扩充一个 [mask] token，起点是"整句全被 mask"，终点是真实句子，训练目标就是"看着一堆 mask，猜每个位置上原来是什么词"。它和 BERT 的掩码预测长得很像，区别在于 BERT 只做一次静态遮挡，而这里遮挡比例是一个随时间从 100% 降到 0 的连续过程，所以它拿到的是一个真正的生成模型，而不是一个填空器。

一句话概括这篇讲的事：扩散模型的成功不依赖"高斯噪声"或"SDE"这些具体零件，它依赖的是一个更抽象的原理——构造一条从噪声到数据的概率路径，然后学着把这条路径的"运动"复现出来。把"运动"从"沿方向移动"换成"按速率跳变"，这套原理就原封不动地适用于文本、DNA 和离散动作。

Why为什么：三个绕不过去的物理与计算约束

这条路线不是"为了统一而统一"的审美选择，它是被三件事逼出来的。

公理一：没有方向，就没有"中间态"，也就没有插值

连续扩散的全部魔力来自"中间态"：加一半噪声的图像仍然是一张图像，它是两个端点之间的一个合法状态，所以你可以从任意中间态起步、可以少走几步、可以做引导。这个能力的物理基础是"空间是连续的"。

离散集合里没有中间态。"猫"和"狗"之间不存在"70% 的猫"。所以你不能定义"加一半的噪声"——你只能定义"这个位置以多大概率已经被换成了别的东西"。这就是为什么离散扩散的"噪声"一定长成"逐 token 独立地被替换/被 mask"，而不是"整体加一个扰动"。

公理二：状态空间大到无法表示，必须靠"稀疏"活下来

这是最硬的一条工程约束，也是外行最容易忽略的一条。长度 L、词表大小 V 的序列，状态空间大小是 V 的 L 次方。GPT 级别的一千个 token、五万词表，这个数字是五万的 1000 次方——不是"很大"，是连把率矩阵的一列存进内存都不可能。

而采样时你偏偏需要那一列：要从当前状态跳到下一个状态，就得知道"从我这个状态出发，跳到每一个邻居的速率是多少"。整列拿不到，CTMC 就没法模拟。

解法只有一个：让率矩阵极度稀疏——只允许"一次跳只改一个位置"。这样"邻居"的数量从 V 的 L 次方降到 L 乘 V，输出形状随序列长度线性增长而不是指数增长。这就是"因子化（factorized）"的全部动机，它不是一个建模偏好，是唯一能算得动的选择。

公理三：边缘化之后，那个"率"其实就是一个分类器

第三条是这篇最漂亮的结论。按连续版的配方，你要先构造"条件率矩阵"（给定一条真实数据，它该以什么速率跳），再把它对数据分布边缘化，得到"边缘率矩阵"（不看答案时该以什么速率跳）。第二步在连续版里是个积分，通常在离散版里会变成一个求和，看起来没法算。

但在因子化 + 逐 token 独立噪声（掩码）这个具体设定下，边缘率矩阵有一个极其简单的形式：它正比于"给定当前带噪序列，第 i 个位置的真实 token 是什么"这个条件概率。换句话说，你要学的那个"跳变速率"，本质上就是"每个位置上，答案是什么"的概率。

这一步把"学一个生成模型"直接翻译成了"在每个位置上做一个分类题"。训练目标于是退化成逐位置的交叉熵——和训练一个语言模型、一个分类器，在代码层面几乎没有区别。这就是"离散扩散实现起来意外地简单"的根本原因。

How怎么拆：五级公理链

把上面三条约束串起来，就得到一条从"离散数据"推到"逐位置交叉熵"的推演链。每一级都只用到上一级的结论，没有跳步。

第 1 级：认输——离散空间没有 SDE，改用"跳"
放弃"沿着方向连续移动"，改成"停在某个状态上，然后以某个速率瞬间跳到另一个状态"。这个过程的数学对象就是连续时间马尔可夫链。它的全部信息都压在一张率矩阵里：非对角元 = 从这跳到那的速率（非负）；对角元 = 离开这个状态的总速率的负数。第二条不是额外假设，是"概率总和必须为 1"逼出来的——你在一个状态上，要么留着，要么跳走，没有第三种可能。
第 2 级：把"演化"写成方程——科尔莫戈罗夫向前方程
给定率矩阵，状态分布怎么随时间变？答案是：每个状态的概率变化率 = 从别处跳进来的流量 − 从这里跳出去的流量。这句话写出来就是科尔莫戈罗夫向前方程（KFE）。它的地位等同于连续版的连续性方程：它是"率矩阵"与"分布轨迹"之间唯一的合法桥梁，后面所有"我构造的率矩阵对不对"的验证，全靠把构造出来的东西代进这个方程检查一遍。
第 3 级：加稀疏约束——一次只允许改一个 token
受 V 的 L 次方这个诅咒，率矩阵必须被限制成"只在两个仅差一个位置的状态之间非零"。于是模型输出从一整列变成一个 L 乘 V 的张量（每个位置一个分布），transformer 恰好天然产出这个形状。这一步是纯粹的工程量换来的可行性，代价是模型永远不能"一步换两个 token"——它必须一个一个改。
第 4 级：条件 → 边缘，边缘化技巧把答案收拢成一个概率
先构造"给定真实答案时的跳变速率的理想值"（条件率矩阵），再用 KFE 证明：把条件率矩阵按"当前状态对应的数据后验"加权求和，得到的边缘率矩阵仍然满足 KFE。这就是离散版的边缘化技巧。在掩码路径下，这个求和坍缩成一句极简的话：边缘跳变速率 = 「给定当前带噪序列，第 i 位是某个 token」的条件概率，再乘上一个由噪声调度决定的系数。
第 5 级：训练退化成分类，采样退化成"按速率掷骰子"
既然边缘率只是一个条件概率，那就把网络定义成"输出每个位置的 token 分布"，用交叉熵训练。采样则从"全 mask"出发，每一步算出每个位置该跳的速率，按速率采样"这一步跳哪里、跳成什么"，跳完再算，直到时间走完。整个过程没有任何"回归一个连续量"的操作，全部是分类与抽样。

Formula核心公式：三个式子把这个框架钉死

① 率矩阵：离散版的"向量场"，只有两个约束
\[ Q_{xy}\ge 0\quad(x\ne y),\qquad Q_{yy}=-\sum_{x\ne y}Q_{yx} \]
\(Q_{xy}\) 是"从状态 \(y\) 跳到状态 \(x\) 的瞬时速率"，单位是"每秒跳几次"。大白话：第一条说"跳到别人的速率不能是负的"（负速率没有物理含义，不跳就是 0）；第二条说"停在原地的速率必须正好抵消掉离开的总速率"——你在原地或者离开，没有第三条路。合起来意味着：这张矩阵对角非正、非对角非负、每列加起来为零。它就是"向量场"在离散空间的化身：向量场告诉你"往哪个方向使劲"，率矩阵告诉你"往哪个邻居跳得快"。
② 科尔莫戈罗夫向前方程：分布怎么随时间流动
\[ \frac{d}{dt}p_t(x)=\sum_{y\ne x}p_t(y)\,Q_{yx}\;-\;p_t(x)\sum_{z\ne x}Q_{xz} \]
\(p_t(x)\) 是 t 时刻处于状态 \(x\) 的概率。大白话：右边第一项是"从别人那儿跳进 \(x\) 的流入量"，第二项是"从 \(x\) 跳走的流出量"，两者相减就是这个状态概率的变化速度——和"水池进水减出水"完全同一个意思。它的作用是当裁判：你随手构造一个率矩阵，代进这个式子如果两边对得上，那它确实能生成你想要的那条概率路径；对不上，就是错的。本文里所有"这个率矩阵是对的"的证明，实质都是把候选者代进这个方程验一遍。
③ 因子化掩码路径下的训练目标：每个位置一道选择题
\[ \mathcal{L}(\theta)=\mathbb{E}_{t,\;y_1\sim p_{\text{data}},\;y_t\sim p_t(\cdot\mid y_1)}\left[-\,\frac{1}{L}\sum_{i=1}^{L}\log p^{\theta}_{i}\!\left(y_1^{(i)}\mid y_t\right)\right] \]
\(y_1\) 是真实序列，\(y_t\) 是它在时刻 t 被 mask 掉一部分后的样子，\(y_1^{(i)}\) 是第 i 个位置的真实 token，\(p^{\theta}_{i}\) 是网络在第 i 个位置上给出的分布。大白话：随手抽一个时间点、随手抽一句真话、按这个时间点该有的比例把它 mask 掉，然后让网络看着残缺的句子，把每个位置原来的词猜回来，猜错就罚。注意三件事：① 损失对 \(L\) 个位置是求和的，所以一次前向就能同时监督所有位置——这正是"并行"的来源；② 没有"回归"，只有分类；③ 那个由调度器决定的系数（即"还剩多少噪声"）在训练时被吸收进了时间采样里，所以代码上看不出它，但它决定了每个时间点该被采样的频率。边缘率矩阵就是从这个分布变换出来的，不需要单独学。
把三个式子连起来看：①定义"能怎么跳"，②规定"跳完分布怎么变"，③告诉你"想跳到数据的分布上，每一步该往哪跳"——而③的答案居然只是"猜每个位置原来的词"。所谓"离散扩散"，剥到最里面，就是一个被时间维度调度起来的、每个位置独立的掩码分类器。

Worth价值与局限：它省掉了什么，又付出了什么

它真正换来的三样东西

第一，一套真正统一的语言。连续 flow、离散扩散、乃至流形上的扩散，在这个框架下不是三个并列的技巧，而是同一个原理（"构造从噪声到数据的路径，然后学着复现这条路径上的运动"）在三类状态空间上的实例。文章末尾点出的 Generator Matching 就是这个统一：把"向量场"和"率矩阵"都看成 generator，于是"扩散模型"这个概念不再绑定于任何一种具体的空间或噪声。

第二，一个极低的实现门槛。训练代码本质上就是"随机 mask → 前向 → 逐位置交叉熵"。没有噪声调度网络、没有方差预测、不需要数值积分器、不需要调 ODE solver 的步数。这对工程团队的意义比学术意义更大：一个懂 transformer 训练的人，几乎不需要额外知识就能把它跑起来。

第三，一个天然并行的生成过程。连续扩散的采样必须按时间顺序一步步积分，步与步之间有严格的因果依赖；而离散扩散里"每个位置的跳"是独立采样的，理论上可以一次改多个位置、也可以乱序改。这是它在推理速度上唯一的、也是最大的结构性希望——虽然本文并没有解决"怎么选顺序、一次改几个"这个工程问题。

五处必须打折的地方

  1. 因子化是"能算"的代价，不是"更好"的选择。一次只能改一个 token，意味着要把一整句从全 mask 变成真话，最少也得走 L 步。它没有解决"生成慢"这个根本问题，只是把"每步积分"换成了"每步一跳"。把这条当成"离散扩散比连续扩散快"，是误读。
  2. "每个位置独立"是一个强假设，不是定理。因子化掩码路径默认各位置被独立破坏，所以边缘率矩阵也因子化。一旦任务需要强位置耦合（比如代码里的括号配对、动作序列里的因果先后），这个独立性就变成了建模误差的来源。它没有错，但它有边界。
  3. 率矩阵的最优性完全取决于调度器。「什么时候该多 mask 一点」这条曲线（调度器）是人为设定的，它直接决定训练时各时间点的采样密度，也决定采样轨迹的形状。文章把它当成给定条件，但它是这类模型最敏感的超参之一——换个调度器，同样的理论、同样的代码，效果可以差一大截。
  4. 它没有回答"离散化本身该不该做"。把连续动作切成 token，会引入量化误差；不切，就不能用这套框架。这是一个上游的取舍，本文默认你已经接受了 token 化。对机器人动作这种物理量来说，这个默认并不总是划算——连续控制里"差一点"恰恰是有意义的，"跳"反而是不自然的。
  5. 它是教科书式的推导，不是"实测对比"。文中给出的是框架、定理与算法，没有在统一协议下与连续扩散做质量/速度的大规模对照。所以它证明了"这条路走得通、而且很优雅"，但没有证明"这条路更划算"。这两件事在工程决策上的分量完全不同。

一句话收尾

这篇的价值不在于又给出了一个能生成文本的模型，而在于它把"扩散"从一个关于高斯的技巧，还原成了一个关于"路径与运动"的原理。一旦你这么看，就会明白：连续扩散之所以要"加噪—去噪"，是因为在连续空间里只能这样定义一条从乱到有序的路径；离散空间里没有加法的余地，所以路径只能由"跳"构成。形式变了，问题是同一个：怎么把一团均匀的乱，沿着一条可控的路径，收拢到数据的分布上。

对做具身智能的人来说，最值得带走的一句是：当你的动作被 token 化、你的输出变成一个离散词表上的选择时，你已经站在离散空间里了——这时候再去套连续扩散的公式，不是"效果差一点"，而是从第一步就没有定义。离散扩散给出的，是那个空间里唯一站得住脚的替代方案。
