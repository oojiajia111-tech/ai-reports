一句话 它测的不是模型懂不懂，是模型的手能不能把懂的东西做出来
💡 第一性原理核心立论

「理解任务」和「完成任务」之间隔着的是一条能算出来的沟。11 个多模态大模型、6 项任务、330 次真机零样本测试，总成功率 44.85%；可一旦按任务拆开，放置积木 89.09%，双臂书写 7.27%，解开充电线 0%——55 次尝试没有一次完成。同一批模型，在目标明确、动作离散的任务上已经接近可用，在需要连续轨迹、柔性变形、实时状态追踪的任务上直接归零。这份榜单最值钱的地方不是排名，是它把「瓶颈在手上，不在脑子里」这句话变成了可复现的数字。

What是什么：一份把「演示视频」换成「可复现证据」的真机榜单

先说它到底在测什么。它不是让模型在仿真里刷分，也不是让模型看别人的操作视频答题，而是让 11 个通用多模态大模型直接驱动真机，在没人教过的情况下完成任务。六个任务、每任务 55 次、共 330 次，全部录像并人工复核。

「零样本」在这份榜单里被定义得非常硬，有四条同时成立：

  • 只给任务说明和评分标准，不给任何示教数据；
  • 不许针对基准任务做专项训练或微调；
  • 评测期间不能改 prompt、不能在线更新参数、不接受人工引导；
  • 真机执行，不接受仿真结果替代。

硬件是两套：双臂移动平台 W1（Airbot Play 机械臂 + 平行夹爪），以及桌面六自由度机械臂 ARX5，都配 Intel RealSense RGB-D 相机。接口是统一的——所有模型共用同一套 prompt 模板与工具接口，每一步接收相机图像与机器人状态（深度、力矩可选），通过工具调用输出末端执行器目标位姿和夹爪指令，再由控制器用逆运动学执行。这一点很关键：它把「工程能力」这个变量控住了，剩下的差距才归因于模型本身。

任务成功次数 / 测试次数成功率卡在哪里
放置较大积木—89.09%目标明确、动作离散，7 个模型 5 次全中

抓取玩偶—61.82%柔性物体，抓点选择
修正等式—45.45%推理没问题，落到棍条上的抓取移动不行

这张表最刺眼的不是 44.85%，是这条从 89.09% 到 0% 的落差。如果模型真的是「理解了就能做」，六个任务的分数不该差这么多——它们考的语言理解难度并不递增。差的是物理侧的三件事：感知精度、空间规划、状态追踪。榜单等于给「语义理解」和「物理操作」之间画了一条实测的刻度线。

Why为什么：三个失败机理，正好对应三级能力降级

报告把失败归成三类，这三类不是并列的，而是一条从语义到几何、再到动力学的降级链。

第一级：细粒度感知——看得见，但看不准

推倒水瓶时判断错高矮；充电线任务里认不出交叉结构，也无法决定该抓哪一段。这类失败最有欺骗性：模型能准确说出「这是一根缠绕的数据线」，却在需要毫米级几何判断的地方失手。VLM 训练在语义标签上，几何精度从来不是它的优化目标。

第二级：空间规划——知道去哪，但走不过去

双臂任务里出现夹爪撞桌面、两臂互碰。这不是「不知道目标在哪」，是「规划不出无碰撞的路径」。通用大模型把位姿输出成一串数字，中间缺的那层运动规划（碰撞检测、可达性约束、关节限位）它并不具备，全靠 prompt 和工具接口兜。接口一简单，这一层的脆弱就暴露了。

第三级：连续状态追踪——每一步都对，连起来就错

充电线是最狠的一题：每拉一次，线的形态就变了；拉错了，结会越收越紧。这要求系统在每次接触后重估状态、修正计划。报告的原话是「把一次次局部操作连接成完整任务」——而这恰恰是当前 Agent 式循环的软肋：它每一步都重新观察、重新推理，但没有跨步的世界模型，所以它不知道「上一步已经把线拉成了什么形状」。0% 不是运气差，是这类任务要求的记忆能力它没有。

把三级串起来看，结论比「模型还不够强」更具体：通用大模型在机器人上的能力，严格按「语义 > 几何 > 动力学」递减。凡是能靠语言和常识绕过去的，它做得不错；凡是必须靠连续物理量闭环的，它断在半路。这也解释了为什么「修正等式」只拿到 45.45%——数学推理是它的强项，可推理结果要落到「移动哪根棍条、抓哪里、移多远」，立刻掉到几何层。

How怎么做：用「换题」和「算钱」两件事堵住刷分

榜单设计上有两个不常见但很聪明的机制。

机制一：月度换题，让背题失效

每月加入新任务，同时通过更换物体、布局和指令来翻新旧任务。这一招直接掐死了「针对任务微调」这条捷径——你今天的 89% 到了下个月可能因为盘子换了位置就掉下来。它把「泛化」从口号变成了每个月的现金流考核。

机制二：把 token 和耗时摆上台面

这是首期最有信息量的部分。报告统计了每类任务的平均耗时与 token 消耗：

任务平均耗时平均 token 消耗
放置积木13.8 分钟约 48 万
抓取玩偶13.1 分钟约 51.8 万
推倒水瓶7.9 分钟约 28 万
书写 Z023.8 分钟约 173.56 万

书写任务的 token 消耗是放置任务的 3.6 倍。原因不难推：每一步动作后都要重新观察、重新判断，必要时还要修正之前的计划；精度要求越高，需要的「观察—推理—执行」轮次越多。

但真正值得注意的是另一组数：GPT-6.2 Astra 以 70% 成功率排第一，同时成功任务的平均执行时间最短，仅 5.6 分钟、约 27.5 万 token。而 182 次失败测试里有 30 次超过 60 分钟（16.5%），148 次成功测试则全部在 60 分钟内完成。

这两句话合起来是一个反直觉的结论：成功率和推理投入没有稳定正相关。报告明确写了「成本与成功率并不存在稳定的正相关关系」。换句话说，失败的任务不是「想得不够久」，而是「想再久也想不对」。如果有人相信「多给模型几轮思考就能解决操作问题」，这组数据是直接的反证——钱花在了错误的方向上。

Formula核心量化：三个能拿去用的口径

报告本身没有给显式公式，以下三条是按它的评分与统计口径做的形式化整理，便于复用到别的评测上。

① 整体成功率：把「部分成功」挡在门外
\[ S = \frac{1}{N}\sum_{i=1}^{N} \mathbb{1}\big[\text{task}_i \text{ 完成}\big], \qquad S = \frac{148}{330} = 44.85\% \]
这是最硬的口径：任务必须完整完成才算 1，否则为 0。解充电线 55 次全 0，写进这个式子就是 0 分，没有「做对了一半」的折扣。大白话：这个指标故意不承认过程分——因为机器人停在半路，产线上就是零产出。
② 进度得分：给「做了一半」留一席
\[ P = \frac{1}{N}\sum_{i=1}^{N} \frac{\text{已完成子目标数}_i}{\text{子目标总数}_i} \]
这是报告里另一个指标。Gemini 4 Neon 成功率不是最高，但综合进度得分 37.50 分全场第一——说明它「能推进得多、但收不了尾」。大白话：成功率问「成了没有」，进度分问「走到哪了」。两个数一起看才有诊断价值：成功率高 + 进度分低 = 稳但保守；成功率低 + 进度分高 = 有能力没闭环。
③ 成本效率：为什么说「多想了也没用」
\[ C_{\text{succ}} = \frac{\sum_{i \in \text{成功}} (t_i \cdot p + n_i \cdot c)}{|\text{成功}|}, \qquad \text{且 } \mathrm{corr}(n, S) \not> 0 \]
左边是单次成功任务的摊销成本，由耗时与 token 两部分构成；右边是报告给出的经验结论——token 消耗与成功率之间没有稳定正相关。大白话：失败任务同样烧时间和 token，所以「平均成本」被失败样本严重污染。这也意味着只看 API 单价来选模型是错的：便宜但成功率低的模型，摊销到每次成功上可能更贵。

Worth价值与局限：0% 到底是坏消息还是好消息

三个值得带走的判断

  1. 0% 不是「模型很笨」，是「这类任务还没有任何方法覆盖」。解线缆要求的能力是「接触后重估状态 + 跨步记忆」，而当前所有参赛者都是无状态的多步 Agent 循环。这类失败是可诊断的，不是不可逾越的——补上世界模型或显式状态估计，这一栏就有机会动。
  2. 「接口统一」这件事本身就是一个结论。同一套 prompt 模板、同一套工具、同一个控制器，模型之间的差距才纯。反过来说：你换一个更聪明的工具接口（比如直接给位姿增量而不是绝对位姿），现在的排名会重排。所以别把名次当模型的绝对能力。
  3. 成本必须和成功率一起看。报告里单次成功成本从不足 0.5 美元到超过 4 美元，相差近十倍，而成功率并不跟着这个成本走。选型时该看的是「每次成功多少钱」，不是「每次调用多少钱」。

四个必须打的折扣

  1. 样本量偏小。每任务 55 次，成功率在 5% 量级时（书写 7.27% 只有 4 次成功），置信区间会很宽。「7.27%」和「10%」在统计上可能分不开。
  2. 没有原生 VLA 参赛。报告自己说「原生 VLA 模型的参赛通道也已开放」——也就是说，这期比的是「通用大模型 + Agent 外壳」，不代表机器人策略模型的上限。下一期大模型 Agent 与 VLA 正面对决，才是真正的对照实验。
  3. 评测方是榜单建设方。RoboChallenge 自建题目、自定评分、自己发布结果。它做了录像与人工复核，透明度不错，但任务的代表性问题仍然由它单方面定义——六项任务能不能代表「通用操作」，没有外部验证。
  4. 硬件只有两套。W1 与 ARX5 都是固定构型。结论能否迁移到灵巧手、人形、移动底盘，未知。
一句话总结：这份榜单真正回答的问题不是「哪个大模型最强」，而是「通用智能离通用操作还差几级台阶」——答案是三级，而且每一级都能被单独测量。最值得带走的两点：① 语义理解已经够用，几何与动力学是硬缺口，靠堆推理轮次补不上（成本与成功率无正相关就是证据）；② 凡是靠语言能绕过去的任务，大模型已经能干活了——所以短期的落地机会在「离散、明确、可复核」的工位上，而不是在需要连续手感的地方。
