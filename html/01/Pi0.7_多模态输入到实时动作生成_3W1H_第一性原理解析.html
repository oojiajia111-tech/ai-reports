💡 第一性原理核心立论

机器人泛化不了，不是数据太少，而是同一个画面对应太多种合理动作——快做还是慢做、关节控还是末端控，数据里全混在一起。π0.7 把"任务描述"升级成行为说明书：语言、质量/速度、控制模态、视觉子目标四类提示，把"这一次该怎么做"逐条钉死。歧义一消，异构本体与人类视频全成了燃料，机器人第一次像 LLM 一样把旧技能拼成新任务。

① 是什么② 为什么③ 怎么做④ 价值与局限

What是什么：一个"可导向"的机器人通用大模型

π0.7 是 Physical Intelligence 发布的通用视觉-语言-动作（VLA）模型，主打一个此前机器人模型没有的能力——开箱即用的专精级性能 + 组合式泛化：

  • 专精级灵巧：大量高难度操作（如浓缩咖啡制作、叠衣、换被套）不微调就能达到此前 RL 微调专精模型 π*0.6 的速度与成功率；
  • 听得懂新话：能执行训练数据里从未出现过的语言指令；
  • 拼出新任务：把学过的技能重新组合去解新问题——比如操作没见过的厨房电器，甚至让一台没有叠衣数据的机器人叠衣服（跨本体迁移 + 技能重组）；
  • 一个模型打天下：跨机器人本体、跨场景、跨任务共用同一套权重，不再"一个任务微调一个模型"。

架构（公开报道）：Gemma3 4B VLM 骨干 + 约 4 亿参数视觉编码器 + 约 8.6 亿参数动作专家（流匹配目标），推理时由高层策略 + 轻量世界模型在线生成子目标图作为额外提示。

Why为什么：卡住泛化的不是数据量，是数据里的"歧义"

公理一：模仿学习吃的是"条件分布"，条件一模糊，学出来就是一锅粥

模型学的本质是 \(P(\text{动作}\mid\text{观测})\)。同一个"拿起杯子"的观测，数据里既有专家的精准示范，也有自主采集的失败重试；既有 5 秒完成的，也有 20 秒磨蹭的。这些全部映射到同一个条件下，模型只能学出一个"平均动作"——看起来哪都会一点，实际哪都不行。

公理二：数据源的多样性恰恰是泛化的来源，扔掉可惜，硬吃会毒

LLM 的组合泛化来自海量异构文本。机器人对应的数据源包括：多种机器人本体的数据、人类第一视角视频、各策略跑出来的自主数据。这些数据行为风格天差地别——但这正是拼装新技能的原材料。 naive 合并训练之前都失败了，因为公理一的歧义被数据多样性放大了。

公理三：要同时满足"多吃数据"和"不歧义"，唯一出路是把条件写满

把"这一次是什么风格的行为"显式写进条件里，条件分布就从多峰坍缩成单峰。这就是"可导向（steerable）"的数学含义：训练时条件标注消歧，推理时条件即旋钮。

How怎么做：把提示从一句话升级成四通道"行为说明书"

Step 1 · 语言指令（做什么）
任务级 + 子步骤级两层描述，如"pick up the oven mitt / open the drawer / fold the towel"。
Step 2 · 元数据（做得怎么样）
质量高低、速度快慢等标签。次优的自主评估数据打上"低质量/低速"标签后就能安全入库，把毒数据变成解歧信号。
Step 3 · 控制模态标签（用什么方式动）
声明该段数据是关节空间控制还是末端（end-effector）控制，让不同本体、不同控制风格的数据在同一框架下共存。
Step 4 · 视觉子目标图（做到什么样）
给出当前子步骤结束时画面"应该长什么样"的图片。训练时来自真值标注；推理时由轻量世界模型在线生成——这让模型拿到训练时没见过的目标外观，是跨场景/跨本体泛化的关键。
Step 5 · 动作专家流匹配解码（实时生成）
四通道提示与视觉观测一起送入 VLM 主干，动作专家以流匹配（flow matching）在动作块上做向量场回归，高频输出连续动作。
动作专家的流匹配训练目标（π 系列通式）
\[ \mathcal{L}(\theta)=\mathbb{E}_{t,\,x_t\sim x_0+(x_1-x_0)t}\;\big\|v_\theta\big(x_t,\,t\,\big|\,o,\;\text{prompt}\big)-(x_1-x_0)\big\|^2 \]
说人话：把"噪声姿态 \(x_0\)"沿直线拖到"真动作 \(x_1\)"，途中随机取一个点 \(x_t\) 让网络猜"此刻该往哪走"（速度场 \(v_\theta\)）。答案永远是一条直线 \(x_1-x_0\)，所以学起来稳、推理快——这就是 π0.7 能实时出动作的原因。其中 \(o\) 是观测，prompt 就是上面四通道"行为说明书"。

Worth价值与局限：从"微调即服务"到"提示即服务"

价值一：数据侧的"垃圾变燃料"。元数据标签让次优自主数据、人类视频、异构本体数据全部可入库，训练数据的获取成本大幅下降——这是所有机器人公司最痛的成本项。
价值二：商业模式被改写。机器人部署从"每个任务请人遥操作采数 + 微调"变成"给 API 发提示词"。Physical Intelligence 已在 2026-10 开放 Pi API beta：传数据、微调、云端推理一条龙。
价值三：世界模型找到了第一个工程落点位。世界模型不再只是"预测下个画面"的研究玩具，而是充当提示生成器，补上"目标长什么样"这块推理时信息。
局限与冷思考：
  1. 官方自己说的是"组合泛化的最初迹象"（first signs）——叠衣跨本体这类演示仍是精选案例，不是全覆盖能力，别把 demo 当产品；
  2. 提示工程负担转移到了人身上：四通道标注（质量/速度/模态/子目标）需要在数据管线里逐条打标，标注体系本身就是新成本；
  3. 世界模型生成的子目标图若失真，会把推理"导向"错误目标——可导向是双刃剑，误差会顺着提示进动作；
  4. 开放性问题：视觉子目标能描述"终态长什么样"，但描述不了接触力学（摩擦、柔顺、双臂受力），精密装配类任务仍靠 RL 专精路线兜底。
